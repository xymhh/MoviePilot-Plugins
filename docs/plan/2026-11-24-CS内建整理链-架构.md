# CS 内建整理链（待整理目录 → 媒体库）架构

> 调研：[2026-11-24-CS内建整理链-调研](2026-11-24-CS内建整理链-调研.md)
> 目标：把「本地下载 → 上传到待整理目录 → 整理到媒体库 → 生成 STRM」整条链收回 CS 内部，
> 不再依赖 MP 整理链与「115网盘CS版」存储适配器。

## 一、目标流程（开 `organize_after_upload` 时）

```
候选/搜索 → [下载前挡：窗口内已 done 的集视为已有]
        → 跨盘下载到本地 /downloads（或 115 分享直存）
        → 上传到「待整理目录」 <p115_transfer_path>/<任务key>/<目标名>
        → CS 整理台扫描该目录：识别 → 重命名 → 批量 move 到 <p115_media_path>/…
        → 触发 STRM 增量（复用 strm_ops）→ 刷新 Emby
        → 写终态 / 通知 / 订阅进度
```

关 `organize_after_upload` 时维持现状：上传直接落到媒体库目标路径 + 交 MP 整理。

## 二、接缝（代码位置）

| 环节 | 位置 | 改法 |
| --- | --- | --- |
| 上传目标 | 跨盘任务创建处写入 `task["target_path"]`（`core/transfer.py:2094` 读取） | 新增分支：开关开时 `target_path = <p115_transfer_path>/<任务key>`，文件名仍用 `target_name` |
| 整理触发 | `handlers/sync/postprocess.py`（整理后处理） | 开关开时不再走 `mp_organize.trigger_mp_organize`，改为调用 `OrganizeService` 的单任务整理 |
| 整理实现 | `core/services/organize.py`（已有 `_build_group_plan` / `_execute_plan` / `_move_targets_batch`） | 新增 `organize_one(source_dir, file_name, mediainfo, season)`：构造单文件 TargetFile 直接走移动+改名，跳过扫描 |
| STRM | `handlers/sync/strm_ops.py`（`_generate_strm` / 增量） | 整理成功后按新媒体库路径生成一次；失败只记 warning，交给 10 分钟增量兜底 |
| 幂等 | `TargetWriter`（`core/target_writer.py`） | 移动前 probe：目标已存在同大小/更大 → 跳过（复用 1.33.0 的 `_probe_same_stem`） |
| 失败 | 漏斗行 | 整理失败按现有 `_fail_row` 退避重试；5 次转 held，并保留待整理目录里的文件（不再留在 /downloads） |

## 三、状态与数据

- 新增配置：`organize_after_upload`（开关，默认关）、`organize_staging_path`（默认空 → 回退
  `p115_transfer_path`）、`organize_staging_cleanup`（整理成功后删空子目录，默认开）。
- 不新增表：整理结果写现有漏斗行 `skip_reason` / `last_error` 与通知，复用 `organize` 的扫描统计。
- 待整理目录里的文件 = 「已上传未整理」的唯一真相；`/downloads` 只放下载中的文件，
  下载完成即上传并删本地（1.10.0 语义不变）。

## 四、边界与风险

1. **不改 MP 存储模块**：这条链不经过 MP 整理，因此不需要「115网盘Plus」。
2. **与漏斗的关系**：漏斗仍是唯一的调度账本（入队 → 认领 → 整理 → 终态），
   只是「整理」这一步的执行者从 MP 换成 CS 整理台。
3. **回滚**：开关关掉即回到 1.34.0 行为；待整理目录里遗留的文件可手动用整理台扫描处理。
4. **不做**：不接管 MP 自己的下载任务整理；不改洗版判定；不动 115 上传并发/熔断。

## 五、验收标准

1. 单测：单文件整理计划（目标路径/改名/字幕跟随）、目标已存在时跳过、失败进退避、
   开关关时行为与 1.34.0 完全一致（回归用）。
2. 全量 pytest 与基线逐条比对；lint 0 error。
3. 真机（灰度）：开关开后跑一集跨盘任务 → 文件落在待整理目录 → 被整理进媒体库 →
   STRM 生成 → Emby 可见；日志给出「已上传待整理 → 已整理 → STRM」三段。
4. 版本 1.35.0；开关默认关，用户确认后再开。

## 1. 背景与现象（已实测确认，不要重新调研）

用户用 TG 发片名 → MP 出 TMDB 候选 → 用户点选 → **只建了第 1 季的订阅**，其余缺集季没有订阅，导致后续季永远不会被自动搜索/补齐。

实机证据（2026-10-12 17:10，MoviePilot V3）：

- 点选候选后只建了 S01（12 集）订阅，`Subscribe` 表里没有 S02 行；用户输入里的季号被丢弃。

根因（代码级）：

1. 点选候选定 → 搜索动作在 `app/chain/interaction.py:973`：
   `SubscribeChain().add(..., season=meta.begin_season, ...)`，TMDB 候选是「整剧」对象，`meta.begin_season` 为 `None`。
2. `app/chain/subscribe/create.py:377-378`：
   `if context.season is None: context.season = 1` → 兜底成第 1 季。
3. MoviePilot V3 原生**支持一次准备多季并原子提交**：`SubscribeChain.async_add_batch(*, title, year, seasons: Sequence[int], batch_writer, ...)`（`app/chain/subscribe/create.py:726`），每季仍落一条 `Subscribe` 行。

现状（插件侧已有的可复用件，**必须复用，不要另造**）：

- `plugins.v2/cloudsubscribe/core/subscribe/service.py:1143 _media_progress(item, season)`：用 `DownloadChain.get_no_exists_info(meta=..., mediainfo=...)` 判断某季在媒体库是否完整，并给出缺失集号。这是本任务判定「缺集季」的标准做法。
- `plugins.v2/cloudsubscribe/core/config.py:51 "auto_subscribe_skip_season_zero": True` + `core/subscribe/service.py:558/600`：榜单自动订阅已有的「跳过第 0 季」判定。
- `plugins.v2/cloudsubscribe/core/hook/subscription.py`：已有包装 `SubscribeChain` 类方法的基础设施（`_install_subscribe_chain_takeover` / `_create_subscribe_chain_wrapper`）。
- 测试基础设施：`tests/plugin_env.py`（`register_mock` / `load_module` / `OwnerDelegator`）+ 参考 `tests/test_subscription_hook.py`、`tests/test_message_title_subscribe.py`。
- 配置热更新：`plugins.v2/cloudsubscribe/__init__.py` 的 `_apply_base_config()`（≈:704）与热更新分支（`hot_keys`，≈:487-530），hook 通过 `OwnerDelegator` 委托读 `self._<key>`（见 `core/delegation.py`）。
- 配置保存/清洗：`core/api/config.py`（例：`:189 payload["auto_subscribe_skip_season_zero"] = bool(...)`）。
- UI 字段：`frontend/cloudsubscribe/src/config/fields/basic.js:34`（`title_subscribe_enabled`）、`fields/subscribe.js:157`（`auto_subscribe_skip_season_zero`）。

## 2. 需求（用户 2026-10-12 明确）

1. 手动订阅（对话框发片名 → 选候选 → 建订阅；以及任何用户手动建订阅入口）**默认按媒体库缺集情况为所有季各建一条订阅**，而不是只订第 1 季。
2. **排除 S00（特辑）**。
3. 只订**有缺集的季**；媒体库已完整的季不建订阅（避免无意义订阅 + 触发插件「网盘洗版：范围=全部/模式=largest」去替换已有文件）。
4. 这些行为必须**在插件 Web UI 里有开关和配置**（可关、可调）。
5. 本轮**不碰搜索源逻辑**（pansou / Dian115 选源、`dian115_auto_unlock` 保持现状，不要关也不要改）。

### 3.1 新模块 `plugins.v2/cloudsubscribe/core/subscribe/seasons.py`

```python
def probe_season_progress(mediainfo, season: int, download_chain=None) -> "_SeasonProgress"
    # 复用 _media_progress 的判定逻辑（deepcopy mediainfo → 只保留目标季 → DownloadChain.get_no_exists_info）
    # 返回 是否完整 / 缺失集号列表 / 总集数；media_source+media_id 无效时视为「未知」，不得抛异常

def resolve_subscribe_seasons(
    mediainfo,
    *,
    skip_season_zero: bool = True,
    limit: int = 0,
    download_chain=None,
) -> list[int]:
    # 1) 季号来源：mediainfo.seasons（dict：季号 -> 集号列表）。
    #    若为空 → 用 MediaChain().recognize_media(mtype=TV, media_source, media_id, cache=False) 重新识别
    #    （参考 app/chain/interaction.py:61-80 的兜底写法）；仍为空则返回 []（调用方回退原行为）
    # 2) 过滤：跳过 season <= 0（含 S00，受 skip_season_zero 控制）；跳过集号列表为空的季
```

- 全程只读：不写文件、不改 MP 数据、不联网除 MP 既有 MediaChain 识别外。

### 3.2 挂钩点 `plugins.v2/cloudsubscribe/core/hook/subscription.py`

新增 `_install_subscribe_add_expansion()` / `_restore_subscribe_add_expansion()`（在 `_install_subscribe_search_takeover()` 里调用安装），包装这两个方法（存在才装，签名自适应，参照已有 wrapper 写法）：

- `SubscribeChain.add`
- `SubscribeChain.async_add`（若存在；同步/异步分别包装）

包装逻辑（满足**全部**条件才展开，否则**原样透传**原函数）：

1. `media_type == TV`（`mtype` 参数或 `mediainfo.type` 判定，兼容两种传参）；
2. 本次调用**未显式指定季号**（`season is None`）——用户/调用方指定了季号就尊重它，不展开；
3. 开关 `subscribe_all_missing_seasons` 为真；
4. 不在「抑制展开」状态内（见 3.3 防重入）；
5. `resolve_subscribe_seasons(...)` 返回的季数 ≥ 1。

展开动作：

- 逐个季号调用**原始** `add(...)`（`season=N`；其它参数原样转发，包括 `**kwargs` 中的 `note/total_episode/start_episode/lack_episode`）；
- 第一条（最小季）沿用原 `message` 参数；其余季传 `message=False`，避免刷屏；
- 返回第一条的 `(subscribe_id, message)`；全部失败时返回最后一个错误信息；
- 每季结果写 `logger.info`（含 title、季号、结果）；
- 季与季之间**不要**新增 sleep/thread；顺序调用即可。

若不满足展开条件 → 直接 `return original(...)`（**必须**保持原参数、原返回值语义，不得吞异常）。

### 3.3 防重入（必须实现）

插件自身「榜单自动订阅」`core/subscribe/service.py::_subscribe_group` 已按季展开并调用 `subscribe_chain.add(season=season)`（`season` 可能为 `None`）。
→ 在 `core/hook/subscription.py` 暴露上下文管理器 `suppress_season_expansion()`（模块级计数/`threading.local` 或 `contextvars`，需线程安全），并在 `_subscribe_group` 调用 `add` 的位置用 `with suppress_season_expansion():` 包裹。
→ 被抑制时包装器必须原样透传。

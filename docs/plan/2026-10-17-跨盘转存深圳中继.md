# 跨盘转存「秒传未命中 → 深圳中继」方案（2026-10-17）

> 状态：讨论已定稿，待实现。用户已确认接受双地区同账号使用风险；插件 6 个开关已提交 `2988ace`（1.6.54，未推 main）。

## 用户确定的形态（与「整体搬迁」不同）

**默认走现有链路，德国不改。** 只有「115 秒传未命中」的那一个文件，才把
「下载源文件 + 上传 115」这两步精准交给深圳；深圳传完后，插件继续执行原有的
整理/重命名/STRM/通知/历史，一步不少。

| 条件 | 谁做 | 做什么 |
| --- | --- | --- |
| 115 秒传命中 | 德国 | 零流量完成，链路不变 |
| 秒传未命中 + 中继开关开 + ≤单文件上限 | 深圳 relay | 解析源直链（本地 cookie）→ Gopeed 下载 → 115 内网上传 |
| 秒传未命中 + 中继关/超限/失败且允许回落 | 德国 | 原有直传/下载上传链路，逐字节不变 |

## 关键代码事实

- 默认模式（`cross_transfer_rapid_miss_action=fallback`）下，秒传判定发生在
  `drive/p115/upload.py:398-414` 的 `upload_file_init`：`reuse=true` → 直接返回
  `"rapid"`；`reuse=false` → 当前立刻进入 Range 直传（`_upload_parts_concurrently`
  或顺序 `upload_file`），源端单连接被夸克拉到 100~200 KB/s（见 `:508` docstring）。
- 所以接缝点在「`reuse=false` 且尚未开始传字节」处，不是下载前。
- 后续整理链路：`handlers/sync/service.py:2770-2800` 用 `result_file_name` /
  `result_sha1` 写回 `file_item["staging_name"]`，再进 `_queue_file_finalize_batch`
  → 重命名/移动/STRM/通知。中继只要返回同样字段，整理完全复用。

## 插件侧改动（约 120 行）

1. `drive/p115/upload.py` 的 `upload_from_link` 增加可选 `on_rapid_miss` 回调：
   `reuse=false` 时若回调存在，先取消上传会话再抛 `RelayHandoffRequired`（携带
   file_size / checksum / 目录信息）。
2. `core/transfer.py` 捕获该异常 → 调 `core/relay.py` 的 `submit()` → 轮询
   `/jobs/{id}`（按 `cross_transfer_relay_timeout_minutes`）→ 成功后
   `target.require(FILE_QUERY).find_file(target_path, target_name)` 取回文件对象，
   写 `method="relay"` 的成功结果（字段与本地上传一致）。
3. 失败按 `cross_transfer_relay_fallback_local`：开 → 重跑本机原链路；关 → 记失败。
4. `core/relay.py`：httpx/requests 客户端，`X-Token` 鉴权，地址为空即禁用。

## 中继收什么（不传直链、不传分享链接）

秒传未命中时源文件**已经转存进用户自己的夸克账号**（跨盘流程先 `transfer_file`
到暂存目录），所以只传身份，不传链接：

```json
{
  "provider": "quark",
  "file_id": "…",
  "file_name": "…mkv",
  "size": 1234567890,
  "sha1": "…",
  "target": {"provider": "p115", "path": "/整理/待整理", "name": "…mkv"}
}
```

深圳用本地夸克 cookie 解析直链（IP 一致，无时效/跨 IP 风险），再交给 Gopeed；
115 侧用 p115client + p115oss，OSS host 改 `oss-cn-shenzhen-internal`。

## 深圳组件

| 组件 | 作用 | 资源 |
| --- | --- | --- |
| relay（Python，单进程） | 收任务、解析夸克直链、编排 Gopeed、上传 115、校验 sha1、清理 | ~70 MB |
| Gopeed | 多连接下载（夸克单连接限速，必须多线程） | ~100–200 MB |
| 磁盘 | 串行，单文件 ≤25 GB（35 GB 盘留余量） | — |

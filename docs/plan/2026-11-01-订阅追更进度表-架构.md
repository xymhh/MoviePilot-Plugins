# 2026-11-01 订阅追更进度表架构与实施方案

> 状态：设计完成 2026-11-01

## 1. 业务目标

将原先被动的「基于已完成流水拼凑的卡片」，重构为以「MoviePilot 原生订阅 + TMDB 官方季集」为绝对基准的**追更作战大屏**。

### 核心定义
- **真相来源**：MoviePilot 订阅实体 (`Subscribe`) + TMDB 分集元数据。
- **追更双引擎**：
  - **来源 1（主动轮巡搜索）**：定时/手动按缺失集数对网盘源进行搜源补集。
  - **来源 2（频道监控实时雷达）**：TG 频道实时抓取消息，碰撞命中缺失集数后无感自动转存。
- **进度大屏**：
  - 汇总展现：全剧总集、已播出集、库内已有集、缺失待补集。
  - 动态可视化：三色进度条（已入库 / 转存中 / 缺失待补 / 未播出）。

## 3. 前端交互与视图组件划分

1. **`MediaHub.vue` 重构**：
   - 筛选标签：`全部订阅` | `追更中` | `有缺集待补` | `已全部完结`
   - 卡片核心呈现：海报、片名、季号、全剧总集数、已入库集数、缺集气泡、双引擎来源徽章。
   - 三色进度条：
     - 绿色：已入库（`library_episodes.length`）
     - 黄色：转存中（`transferring_episodes.length`）
     - 灰色：缺失已播出（`missing_episodes.length`）
     - 浅色底：尚未播出
2. **`MediaDrawer.vue` 升级为分集追更矩阵**：
   - B站/爱奇艺式选集网格：
     - 点击任一集数查看该集转存状态/画质/来源；
     - 对缺集支持「单集立即搜源」；
     - 对失败集显示原因并一键重试。

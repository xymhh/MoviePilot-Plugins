# 任务书：aria2 内置下载引擎（CloudSubscribeX 1.8.0）

> 前置：`docs/plan/2026-10-31-aria2内置下载引擎-调研.md`、`…-架构.md`（已过审，用户接受 GPL-2.0 分发与仅 x86_64）
> 执行者：外部 ACP agent。**不要 git commit / push**，产物留在工作区由主 agent 验收后统一提交。

## 0. 背景（够你独立判断）

CloudSubscribeX 的跨盘转存有一条"下载腿"：`core/transfer.py` 里的 `HttpFileDownloadService`（多线程 Range 拼接，约 300 行）。现在要给它加一个**可选**的第二引擎：**插件自带的 aria2c 子进程**（不是外部容器、不是外部 RPC 端点），由插件自己拉起、自己管生命周期。

关键事实（已实测，别再自行压测）：

- 宿主 MP 容器：Debian 13 / x86_64 / glibc 2.41 / Python 3.12 / 4 核 / 12 GB / 有 root、无 aria2c。
- aria2 与裸 curl **同连接数同速**；所以本任务的正当性是续传/调度/单进程吃连接，**不要**在文档/日志里承诺"更快"。
- 夸克直链必须带 `cookie` + `user-agent` + `referer`；96 连接是有效上限，128 反而更差。

#### `binary.py`

```python
BINARY_SHA256 = "36f66dab69edcc44255d0dba90c93f5aa4a304ec60c7136d8c279dfc89c23e1d"
BINARY_NAME = "aria2c"

def ensure_binary(target_dir: Path) -> tuple[Optional[Path], str]:
    """解压 bin/aria2c-linux-x86_64.xz → target_dir/aria2c，校验后返回 (path, "")。
    失败返回 (None, 原因)。原因只能是这几条之一，便于日志与单测断言：
    "unsupported-platform" / "archive-missing" / "checksum-mismatch" / "probe-failed"
    """
```

要求：

- 平台判定：`sys.platform == "linux"` 且 `platform.machine()` 归一化后 ∈ `{"x86_64", "amd64"}`；否则 `unsupported-platform`。
- 压缩包位置：`Path(__file__).resolve().parents[2] / "bin" / "aria2c-linux-x86_64.xz"`（即 `plugins.v2/cloudsubscribex/bin/`，文件已存在，勿改）。
- 解压用标准库 `lzma`，**不要**依赖 `xz` 命令。
- 目标已存在且 sha256 正确时**不重复解压**（幂等，避免每次启动写盘 9MB）。
- `chmod 0o755`；最后跑一次 `[bin, "--version"]`（`timeout=5`，`stdout=PIPE`），非 0 或输出不含 `aria2 version` → `probe-failed`。

#### `rpc.py`

```python
class Aria2Error(RuntimeError):
    code: int
    message: str

class Aria2Rpc:
    def __init__(self, port: int, secret: str, timeout: float = 5.0, host: str = "127.0.0.1")
    def call(self, method: str, params: list | None = None, timeout: float | None = None) -> Any
    # 便捷封装（都走 call）
    def get_version(self) -> dict
    def add_uri(self, uris: list[str], options: dict) -> str
    def tell_status(self, gid: str, keys: list[str] | None = None) -> dict
    def change_uri(self, gid: str, uris: list[str]) -> list
    def force_pause(self, gid: str) -> str
    def remove(self, gid: str) -> str
    def remove_download_result(self, gid: str) -> str
    def shutdown(self) -> str
```

- 用 `urllib.request`（禁止新增第三方依赖），`Content-Type: application/json`，参数首项固定 `"token:<secret>"`。
- 响应里带 `error` → 抛 `Aria2Error(code, message)`；HTTP/网络异常 → 抛 `Aria2Error(-1, str(err))`，**不要**吞掉。
- 单次调用超时可控（`timeout` 参数覆盖默认）。

#### `engine.py`

```python
class Aria2Engine:
    def __init__(self, settings: Aria2Settings)
    @property
    def ready(self) -> bool
    def ensure_started(self) -> bool          # 幂等；失败返回 False 并记 warning（只记一次）
    def rpc(self) -> Aria2Rpc                 # ensure_started 失败时抛 Aria2Error(-1, "engine-not-ready")
    def stop(self) -> None                    # 幂等；terminate → wait(3) → kill
```

启动参数（**逐字按此顺序**，便于真机 `ps` 核对）：

```
<aria2c> --enable-rpc --rpc-listen-all=false --rpc-listen-port=<port> --rpc-secret=<secret>
 --dir=<download_dir> --file-allocation=none --continue=true
 --max-concurrent-downloads=<max_concurrent> --max-connection-per-server=16 --split=16
 --min-split-size=<min_split_size> --disk-cache=<disk_cache>
 --auto-file-renaming=false --allow-overwrite=true --check-certificate=true
 --follow-torrent=false --enable-dht=false --bt-enable-lpd=false
 --console-log-level=warn --summary-interval=0 --quiet=true
 --log=<data_dir>/aria2.log --save-session=<data_dir>/aria2.session --save-session-interval=30
 --stop-with-process=<os.getpid()>
```

- 端口：`bind(("127.0.0.1", 0))` 取空闲端口后立刻 close 再用（允许极小概率冲突，冲突时重试一次）。
- secret：`secrets.token_hex(16)`，只在内存，不落盘、不写日志。
- spawn：`subprocess.Popen(..., stdout=DEVNULL, stderr=DEVNULL, start_new_session=True)`；`--stop-with-process` 保证 MP 退出后 daemon 自灭。
- 就绪探测：`getVersion()` 轮询，每 200ms 一次，最多 10s；失败 → 停掉进程、返回 False。**最多重启 2 次**（`_restart_budget`），超出后本次运行不再尝试。
- `--log` 指向 `<data_dir>/aria2.log`；data_dir 由 `Aria2Settings.data_dir` 给出（插件数据目录），需要 `mkdir(parents=True, exist_ok=True)`。
- 线程安全：`ensure_started`/`stop` 用 `threading.Lock` 保护（多个跨盘任务会并发进来）。

#### `service.py`

```python
class Aria2FileDownloadService:
    def __init__(self, resolver: Callable[[CloudFile], tuple[str, dict]],
                 timeout: int = 300, concurrency: int = 5, part_size: int = 0,
                 link_refresh_interval: float = 30.0, link_max_age: float = 1200.0,
                 max_retries: int = 6)
    def download_file(self, file_item: CloudFile, local_path: str,
                      progress_callback=None, stop_requested=None,
                      preserve_partial: bool = False) -> str
```

语义必须与 `HttpFileDownloadService.download_file` 对齐：

1. 复用 `core.transfer._LinkRefresher`、`_ProgressGate`（直接 import，不要复制实现）。
2. `add_uri` 的 options：`split` = `max-connection-per-server` = 生效连接数（`min(settings.connections, 96)`），`min-split-size`、`dir`（= `Path(local_path).parent`）、`out`（= 文件名）、`continue="true"`、`file-allocation="none"`、`auto-file-renaming="false"`、`allow-overwrite="true"`、`header=[f"{k}: {v}" for k, v in headers.items()]`。
3. 进度：`tell_status(gid, ["completedLength","downloadSpeed","connections","status","errorCode","errorMessage","totalLength"])`，**800ms** 轮询一次，喂 `_ProgressGate`（`gate.update(int(completed))`，具体方法名照 `core/transfer.py` 里现有的用）。
4. `stop_requested()` 为真 → `force_pause` → `remove` → `remove_download_result` → 删 `<local_path>.aria2`；`preserve_partial` 决定是否保留半成品；抛 `RuntimeError("已取消")`（与现实现一致——先核对现有实现抛的类型，保持一致）。
5. 失效恢复：`errorCode ∈ {3, 19, 24}` 或 `status == "error"` → `refresher.get(refresh=True)` 取新链接 → `change_uri(gid, [new_url])`，**最多 2 次**；仍失败 → 抛错（由接缝层回落）。
6. 完成校验：`status == "complete"` 后，`file_item.size > 0` 时要求 `int(completedLength) == int(file_item.size)`（不符抛 `RuntimeError`）；删 `<local_path>.aria2`；返回 `str(local_path)`。
7. 无论成功失败，都要 `remove_download_result(gid)`（避免 aria2 结果列表无限增长）；清理逻辑放 `finally`。

  if self._delegate is not None:

          logger.warning(f"aria2 下载失败，回落内置下载器：{file_item.name}（{error}）")

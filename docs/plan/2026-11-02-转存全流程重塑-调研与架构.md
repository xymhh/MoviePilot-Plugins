# 转存全流程三大核心重构 · 调研与架构设计

> 日期：2026-11-02
> 目标：一次性根治「跨盘电影未识别（397条）」、「失效/报错误报无可用文件（218条）」、「单集未更新旧资源反复空转」三大系统性顽疾。

## 一、现状与病因剖析

### 1. 跨盘电影 397 条「未识别」病因
- **现状**：夸克等网盘上的电影文件常被命名为 `2026.1080p.mp4` 或短字符串，电影真实标题只存在于**父目录名**（如 `2026犯罪《你-能-看-到-一-切》`）或**资源分享标题**（如 `你能看到一切（2026） 中英字幕`）中。
- **病因**：`matching.py:73` 原有兜底设计意图是「发布标题 + 唯一视频」，但调用了要求**严格全等**的 `FileMatcher.media_name_matches`。因未剥离全角括号年份 `（2026）`，比对恒为 False，兜底 100% 暴毙。且完全没有利用**视频所在的父目录名**。

### 2. 夸克 218 条「无可用文件」病因
- **现状**：账本中大量 `【吞噬星空】更新至第242集` 等资源被标记为 `empty: 无可用文件`。
- **病因**：
  1. 夸克驱动 `list_share_files` 在底层将所有网络/接口/鉴权异常 `except Exception` 后直接 `return []`；
  2. 上层 `resources.py:_validated_resource_files` 将空列表盲目判定为 `SkipStatsCollector.KIND_EMPTY: "无可用文件"`。
  3. 真实的「接口异常/失效」被伪装成了「网盘有这个目录但目录是空的」，掩盖了真实错误。

### 3. 集号未更新的旧资源每轮空转病因
- **现状**：《我的有罪之人》等剧集，搜索渠道返回的分享只更新到第 4 集，而订阅需要第 5 集。每轮扫描重复出现，几十次调用网盘 API 打开目录。
- **病因**：现有的 `mismatch_seen` 负缓存仅在「标题不符」时记录。对于 `episode_miss`（集号不满足缺失集），完全没有记录资源当前已包含的集数上限，导致每轮扫描对同一个未更新的 URL 反复拉取文件树。

## 二、架构与改造设计

### 1. 电影模糊兜底匹配增强（`matching.py`）
- 引入**双重语义兜底**：
  1. **层级一（发布标题包含匹配）**：改用 `resource_title_matches(resource_title, expected_titles, expected_year)`，支持分词、包含、年份匹配与标点归一化；
  2. **层级二（父目录名包含匹配）**：取唯一视频的父目录（如 `2026犯罪《你-能-看-到-一-切》`），去除连字符与书名号后比对；
  3. **层级三（多清晰度容错）**：若分享内包含 1 个以上视频，但所有视频均为该电影的不同清晰度版本（如 4K + 1080p），允许取最大体积版本，不再因 `len(fallback) != 1` 轻易放弃。

### 2. 网盘列表异常与空目录严格分流（`drive/quark/share.py` & `resources.py`）
- **驱动层**：夸克 `list_share_files` 发生底层异常时不静默返回 `[]`，而是显式抛出 `RuntimeError`，附带真实错误信息；
- **业务层**：`resources.py` 对 `list_share_files` 显式捕获异常，记录为 `SkipStatsCollector.KIND_INVALID: f"读取分享失败：{err}"`；仅在 API 明确返回成功且结果确为 0 个文件时，才记录为 `KIND_EMPTY: "无可用文件"`。

### 3. 集号差（`episode_miss`）负缓存（`candidate_filter.py`）
- 新增 `remember_episode_miss(share_url, resource_title, available_episodes, ttl=6*3600)`；
- 新增 `episode_miss_seen(share_url, resource_title, missing_episodes) -> bool`：
  - 若在 6 小时内已解析过该链接，且记录的 `available_episodes` 仍然无法覆盖当前需要的任何 `missing_episodes`（即资源未更新），直接跳过 `_validated_resource_files`；
  - 若用户订阅发生变化或发现新缺失集，动态失效或放行。

## 三、验收标准
1. **单元测试**：
   - 包含《你能看到一切（2026） 中英字幕》及父目录 `2026犯罪《你-能-看-到-一-切》` 的电影单测全部通过；
   - 夸克列表异常与真实空目录的分类断言通过；
   - 集号未更新跳过单测通过；
   - 全量单测 ≥ 1269 tests 全部通过，lint 0 error。
2. **线上真机**：
   - 重新扫描后，跨盘电影「未被识别」大幅下降或清零；
   - 虚假的「无可用文件」不再产生；
   - 扫描耗时明显降低（重复旧资源被 6h 缓存拦截）。

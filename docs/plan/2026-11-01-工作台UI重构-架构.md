# 2026-11-01 CS插件工作台UI重构架构设计

> 状态：设计完成 2026-11-01

## 1. 目标与设计原则

彻底解决目前 CS 插件「按钮满天飞、状态到处藏、排障靠翻流水」的混乱现状，从**底层流水型插件**转变为**合格的以影视媒体为中心的追更产品**。

### 原则
1. **以剧集/媒体为中心**：用户追的是《某剧》，不是“第 283 号转存任务”。所有状态（更新、转存、跳过、洗版）优先聚合在剧集卡片上。
2. **高频露脸，低频归拢**：主操作只留「立即同步」「手动添加」「设置」，其余维护工具（缓存、离线、整理）收纳进更多菜单。
3. **穿透式排障**：在单部剧的卡片抽屉里直接看跳过原因与单集重试，不强制跳转到大账本里翻找。

## 3. 核心功能与模块划分

| 模块 | 职责与变更 | 对应改动位置 |
| --- | --- | --- |
| **TopHeader** | 仅保留核心动作；离线任务/清理缓存/网盘整理整合进 `v-menu`（更多操作） | `AppPage.vue` 顶部 |
| **MediaHub** (新建) | 追更聚合卡片流：按订阅/剧集聚合状态、缺集与异常标记、单剧详情抽屉 | `src/components/dashboard/MediaHub.vue` |
| **MediaDrawer** (新建) | 单剧集详情抽屉：单剧季集清单、各集来源、跳过原因、单集排障操作 | `src/components/dashboard/MediaDrawer.vue` |
| **GlobalLedger** | 收敛整合 `HistoryTable` 与 `CandidateLedgerPanel`，作为高级排障专用流水页 | `src/components/dashboard/HistoryTable.vue` |

> 依赖：`docs/plan/2026-11-02-Doctor体检-调研.md`

## 1. 职责划分

| 组件 | 职责 |
| --- | --- |
| `core/api/doctor.py::DoctorApi` | 聚合各检查项，逐项隔离执行（单项失败不影响其他项），输出统一结构 |
| `core/api/registration.py` | 注册 `GET /doctor` 路由（`auth: bear`） |
| `frontend/.../DoctorDialog.vue` | 红绿灯列表 + 修复指引 + 重新体检 |

## 2. 接口

`GET /api/v1/plugin/CloudSubscribeX/doctor`

```json
{
  "success": true,
  "data": {
    "checked_at": "2026-11-02 10:00:00",
    "overall": "ok|warn|error",
    "counts": {"ok": 5, "warn": 1, "error": 0, "skip": 2},
    "items": [
      {
        "key": "plugin_db",
        "name": "插件私有库",
        "status": "ok",
        "detail": "转存流水 2696 条 / 同步作业 12 条",
        "hint": null,
        "fix_tab": null,
        "ms": 12
      }
    ]
  }
}
```

- `status`：`ok` / `warn`（能用但该看） / `error`（功能已坏） / `skip`（未启用或未配置，不算坏）
- `overall`：有 error → error；否则有 warn → warn；否则 ok。`skip` 不参与。

## 3. 检查项（8 项，全部本地可判，只有 TMDB 走一次网络）

| key | 判定 | 红/黄条件 |
| --- | --- | --- |
| `plugin_db` | `store.initialize()` + history/jobs 计数 | 打不开 = error |
| `history` | 最近一条成功流水距今 | 无成功记录或 >72h = warn |
| `subscribe` | 订阅总数、剧/影拆分、缺集剧数 | 0 条 = warn |
| `search` | 已注册可用搜索渠道数量（纯本地，不发请求） | 0 个 = error；刚好 1 个 = warn（单点） |
| `drive` | `drive_manager` 当前网盘是否注册成功 | 未注册 = error |
| `tmdb` | `api.themoviedb.org/3/configuration` 探活（401/200 都算通，超时/5xx = 不通） | 超时 = warn（网络类，不判死） |
| `cache` | `cache_stats()` 命中率 / 解码失败数 | 解码失败 >0 = warn |
| `media_dir` | 整理源目录 `organize_source_path` 存在且可写（未配置则 skip） | 不存在 = error |

阈值集中在模块顶部常量，便于后续调。

## 4. 失败与降级

- 每项 `try/except` 包裹，异常本身变成该行的 `detail`（`error`），**绝不让一次体检 500**。
- 整体加 15s 预算：TMDB 单项 6s 超时，其余本地项 <100ms。
- 前端失败时显示原始错误行，不吞。

## 5. 并发与限流

- 单次请求串行执行（本地项极快），不做缓存，随点随测。
- 不做后台定时任务，避免和生产同步抢资源。

## 6. 需求变更纪律

后续新增检查项 = 在 `_CHECKS` 里加一个函数 + 一条阈值，**不改接口结构**、不改前端渲染逻辑。
文档没写的检查项不加。

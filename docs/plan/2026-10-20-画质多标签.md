# 画质多标签 — 参考 PanSou 资源卡样式

> 状态：已完成 2026-10-20 → [../summary/2026-10-20-画质多标签.md](../summary/2026-10-20-画质多标签.md)

## 目标

频道监控卡片不再只显示一个 `4K.HDR10.HEVC` 长标签，而是按资源站样式拆成多个短标签：

`免费` / `4K` / `杜比视界` / `内封简繁英` / `中字` / `杜比全景声` / `DDP5.1` / `AAC2.0`

参考截图：PanSou 搜索结果卡，标签为主标题下的彩色小 chip。

## 数据设计

`parse_quality()` 在原有 `resolution/hdr/codec/audio/group/rank_key` 基础上增加：

- `subtitle`：`内封简繁英` / `内封简繁` / `中字`
- `source`：`WEB-DL` / `BluRay` / `REMUX` / `HDTV`（只存不展示）
- `free`：标题含「免费」
- `tags`：展示用短标签数组，顺序为 免费 → 分辨率 → HDR/杜比视界 → 字幕 → 音轨

`label` 与 `rank_key` 保持不变，避免影响已有画质排序、回退与转存策略。

## 兼容

1.7.14/1.7.15 的旧 `quality` 对象只有 `label/rank_key`，没有 `tags`：

- `_fill_missing_quality()` 保留原 `label`，只补 `tags/subtitle/source/free/audio`；
- 前端拿不到 `tags` 时回退显示原 `label`，不会空白。

## 验收

- 中文 `杜比视界`、`杜比全景声` 能识别；
- `DDP 5.1` → `DDP5.1`，`AAC 2.0` → `AAC2.0`；
- `免费`、`中字`、`内封简繁英` 能进入标签；
- 相关单测、全量测试与前端构建通过。

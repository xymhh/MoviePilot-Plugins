## 四、UI 结构（对齐上游 `RuntimeCard.vue`）

每条任务一行 `task-row`：

1. **头部**：状态图标 + 标题 + 媒体类型 chip + 状态 chip（搜索中带转圈）
2. **状态行**：阶段文案（`taskPhaseText`，已中文化）+ 耗时（`formatDuration(elapsed_seconds)`）+ 右侧操作
3. **搜索渠道明细**（`search_channels` 非空时）：横向胶囊，每渠道显示名称 + 图标 + 状态（转圈/✓/✗/⏱/熔断）+ 结果数 + 耗时，`title` 悬浮显示错误
4. **进度条**：确定进度显示百分比 + 渐变色；不确定（搜索中）显示 indeterminate
5. **展开明细**（点击展开）：当前文件 `current_file`、后处理分步 `postprocess_steps`（每步图标 + 名称 + 状态）、下载/上传字节与速度
6. **操作**：`canStop(task)` 时显示停止按钮 → `emit("stop-task")`
7. **空态**：`active` 时转圈「处理中」，否则「暂无任务」

## 五、数据落在哪

- 无新增持久化、无 schema 变更、无 SSE 协议变更。
- 展开状态本地 `expandedTaskIds: Set<string>`，不持久化。
- 耗时用现有 `now` ref 每秒刷新（上游同款），不新增定时器。

## 六、失败与回滚

| 情况 | 行为 |
| --- | --- |
| 字段缺失（老任务/未更新后端） | 前端 `?? []` / `?? 0` / `?? ""` 兜底，不抛错不空白 |
| `search_channels` 非数组 | `Array.isArray()` 守卫，按空处理 |
| `elapsed_seconds` 缺失/异常 | `formatDuration` 返回 `--` |
| SSE 断开 | 沿用 `useRuntimeData` 现有轮询兜底 |
| 回滚 | 单文件 revert `RuntimeTaskStrip.vue` + `taskUtils.js` 新增函数，无后端影响 |

## 七、并发与限流

- 不新增请求，仍走既有 `/runtime` 快照 + SSE。
- 渲染上限沿用 `visibleTasks`（最多 5 条 + 「还有 N 条」）。
- 渠道胶囊数量按实际渠道数（当前配置 2 个：pansou/seedhub），不做虚拟滚动。

## 2. 关键约束

1. **门面零改动**：`SyncHandler` 的公开方法名、参数、返回结构一字不改；`_COMPONENT_TYPES` 只追加新 mixin。
2. **方法体逐字搬运**：除缩进外不改任何一行；`import` 一并迁到新模块，`service.py` 里不再被引用的导入删除。
3. **MRO 顺序**：新 mixin 追加到 `_COMPONENT_TYPES` 末尾（现有序：Movie/Television/History/HistoryCleanup/... /PlatformHistory），**末尾追加不加塞**，避免覆盖语义变化。
4. **`__init__` 只拆不改**：407 行 `__init__` 拆成 `_wire_storage()` / `_wire_drive()` / `_wire_search()` 等子方法，装配顺序与赋值必须完全一致。

## 3. 验收（硬证据，不靠人眼）

### 3.1 等价性指纹脚本 `scripts/verify_split_equivalence.py`

- 从两个 git 引用（或工作区）各自 AST 抽取**所有类方法的源码**
- 规范化：`textwrap.dedent` + 去空行 + 去行尾空格
- 建立 `{方法名: sha256(方法体)}` 映射
- 断言：**旧文件的每个方法在新代码中都存在且哈希一致**；方法总数不变；无重复方法名
- 输出 `docs/test/YYYY-MM-DD-拆分等价性.md`（含每个方法的 pass/fail 与总表）

这一条比「跑单测」更强：单测只覆盖有断言的分支，指纹覆盖每一行。

### 3.2 每批次固定动作

```
python3 scripts/verify_split_equivalence.py --before <prev> --after <new>
python3 scripts/lint.py --all                                  # 0 error
python3 docs/test/test_bypass_guard.py                         # 20 断言
python3 docs/test/test_subscribes_progress_isolation.py         # 追更表口径
python3 scripts/check_frontend_entry.py
```

四项全绿才 commit，一批一个 commit（消息里写搬了哪些方法、多少行）。

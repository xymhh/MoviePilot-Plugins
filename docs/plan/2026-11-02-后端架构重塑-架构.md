## 二、四大核心设计规格

### 1. 任务上下文（TaskContext 契约）
```python
class TaskContext:
    run_id: str                      # 任务唯一批次号（如 "20261102_153022_941"）
    started_at: float                # 任务起始时间
    timeout_budget: float            # 单轮最大允许超时时间（秒）
    _cancel_event: threading.Event   # 取消信号标志

    def is_cancelled(self) -> bool:
        """检查任务是否被用户或系统请求停止。"""
        return self._cancel_event.is_set()

    def check_alive(self) -> None:
        """若已取消或超时，立即抛出 TaskAbortedError 快速退出。"""
        if self.is_cancelled():
            raise TaskAbortedError("任务已被手动中止")
        if time.time() - self.started_at > self.timeout_budget:
            raise TaskTimeoutError("任务执行超出时间预算")

    def report_progress(self, current: int, total: int, phase: str) -> None:
        """向前端与日志统一上报当前调度进度。"""
```

### 2. 结构化异常体系（分类与自愈协议）
彻底淘汰裸 `except Exception: return []`，异常分为四级：
1. **`NetworkError`（可重试异常）**：底层 Socket 超时、代理握手失败。**策略**：按指数退避重试（重试 2 次），仍失败则登记下轮补偿；
2. **`AuthExpiredError`（需人工干预）**：115 Cookie 失效、夸克 Token 过期。**策略**：立即熔断当前盘转存，发系统通知告警，不再对后续 100 个订阅持续报错；
3. **`ResourceInvalidError`（分享自身失效）**：分享被作者删除、违规屏蔽。**策略**：准确归入 `KIND_INVALID`，不污染「无可用文件」，不再重试；
4. **`MatchMismatchError`（逻辑不匹配）**：集号差、根目录不匹配。**策略**：记入 6h 负缓存，下轮免空转。

### 3. 统一网盘驱动适配器（DriveStorageAdapter）
所有网盘（115、夸克、移动云盘、阿里云盘、UC）必须继承统一基类：
```python
class DriveStorageAdapter(ABC):
    @abstractmethod
    def check_link(self, share_url: str) -> LinkStatus: ...

    @abstractmethod
    def list_share_files(self, share_url: str, **kwargs) -> List[StandardFileItem]: ...

    @abstractmethod
    def transfer_to_target(self, share_url: str, files: List[StandardFileItem], target_path: str) -> TransferResult: ...
```
- 统一返回 `StandardFileItem`（包含标准 `name`, `size`, `is_dir`, `relative_path`），严禁驱动私自返回特殊键名（消除大小写 `caId` 与 `caID` 这类低级失误）。

### 4. 数据库 `schema_version` 迁移规范
- 私有库首张表建为 `schema_version`：
  ```sql
  CREATE TABLE IF NOT EXISTS schema_version (
      version INTEGER PRIMARY KEY,
      applied_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
      description TEXT
  );
  ```
- 插件启动时，自动比对当前代码最大版本号，按版本号增量执行 `.sql` 或迁移函数，杜绝表结构断层。

## 三、回滚策略与并发限流

1. **失败与回滚**：任何数据库迁移均包裹在 `BEGIN EXCLUSIVE TRANSACTION` 事务内，失败立即回滚，库文件保持原子安全；
2. **并发与限流**：
   - 跨盘下载并发上限锁定为 `2`（避免撑爆宿主带宽高峰与文件句柄耗尽）；
   - 网盘 API 调用频率单驱动强制限速 `>= 200ms/req`，防止被网盘风控封禁。

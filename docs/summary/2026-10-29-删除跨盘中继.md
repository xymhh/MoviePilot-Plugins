# 删除「跨盘中继」功能（含 UI）— 2026-10-29

> 版本：1.7.106（相对 1.7.105 做纯减法）

## 为什么删

中继这条路是为「海外 VPS 上传 115 慢」准备的旁路：秒传未命中时把整份文件交给外部中继服务下载+上传。
实际使用中：

- 中继服务本身不稳定（`47.112.16.239:8787` 探测 `http=000`，从未真正跑通一次生产转存）；
- 它带来的额外配置面（地址/令牌/上限/超时/线程/一律走中继/失败回落）共 8 个开关，
  配置错任何一项都会静默退回本机链路，排查成本远大于收益；
- 用户已明确「不再要这个功能」。

结论：整条删掉，保留原有的「秒传探测 → 本机下载 → 上传」链路。

## 没变什么（回归红线，已用测试守住）

- `cross_transfer_rapid_miss_action`：`abort` = 探测未命中即中止、不下载不上传；其它值走本机下载→上传。
- `RemoteSha1RangeReader` 零流量探测、SHA1 缓存复用、目标写入 `TargetWriter` 的去重/串行化。
- 历史合并、洗版回写、`task_types` 重算。

裁剪处唯一需要留意的语义变化：原先「探到未命中 → 先试中继 → 再 abort」的三段式，现改为「未命中 → 直接 abort」；
由于中继从未在生产上成功接管过，实际行为与关闭中继时完全一致。

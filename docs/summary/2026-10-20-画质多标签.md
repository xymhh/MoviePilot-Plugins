# 画质多标签（1.7.16）

## 结果

频道监控资源标题下改为多个短标签，参考资源站样式：

`免费` `4K` `杜比视界` `内封简繁英` `中字` `杜比全景声` `DDP5.1` `AAC2.0`

不再整段显示 `4K.DOLBY VISION.HEVC`。

## 提取范围

- 分辨率：`4K` / `1080P` / `720P` / `8K`
- HDR：`杜比视界` / `DOLBY VISION` / `HDR10+` / `HDR10` / `HDR` / `SDR`
- 字幕：`内封简繁英` / `内封简繁` / `中字`
- 音轨：`杜比全景声` / `ATMOS` / `DDP5.1` / `DDP2.0` / `AAC2.0` 等
- 其它：`免费`

## 设计取舍

- `tags` 只用于展示，不参与 `rank_key`；画质排序、同集选优、低画质 pending 兜底均不变。
- `label` 继续保留技术串，供旧前端、日志和排障使用。
- 旧 quality 对象补 tags 但不覆盖已有 label，避免改变人工标签和历史排序。
- 字幕只取一个主标签，避免「中字 / 中英 / 简中」同时出现导致卡片噪声。

## 验证

见 [../test/2026-10-20-画质多标签单测.md](../test/2026-10-20-画质多标签单测.md)。

## 边界

- 标题没有分辨率、杜比、字幕、音轨时，`tags` 为空，卡片不显示空标签。
- 「免费」是资源属性，不是画质属性；放进同一行只为了对齐参考样式，不参与选优。
- 标签取自**标题文本**，标题没写的信息无法推断。

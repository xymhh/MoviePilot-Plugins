# 综艺「第N期」→ 集号换算做成可配置（1.7.38）

> 状态：已完成并上线 2026-10-24

## 问题

夸克分享 `/s/5a3a683d45fa` 根目录名是「第3期上」，实际是
**现在就出发 S04E05**。

- 平台解析 `第3期` → `E03`，而订阅 S04 只缺 E05
- `missing_episode_set & share_episodes` 为空 → `KIND_MISMATCH`
- 日志：`本次跳过 1 个候选资源：内容不匹配 1（夸克网盘 1）`，`共转存 0 个文件`
- 手动添加同样被这条规则拦掉 —— 用户「手动也没效果」的实测原因

## 结论：不能写死，要可配置

不同综艺的期集关系不一样：
- 现在就出发 S01：第15期 = E15（每期 1 集）
- 现在就出发 S04：第1期上=E01、第1期下=E02 … 第3期上=E05（每期 2 集，上下各一集）

所以做成插件配置项，按节目自己填。

## 实现

| 位置 | 改动 |
| --- | --- |
| `core/config.py` | 默认配置新增 `period_episode_rules: ""` |
| `__init__.py` | `_parse_period_episode_rules()` 解析「节目名 = 每期集数」，`init_plugin` 注入 `FileMatcher.period_episode_rules` |
| `utils/file_matcher.py` | `period_episode_override()`：命中配置节目 + 文件名含「第N期」时 `episode = (N-1)*size + 半场偏移 + 1`；半场偏移 上/无=0、中=1、下=size-1 |
| `frontend/.../config/fields/basic.js` | 新增「期集换算规则」textarea |

边界：
- 配置为空 → 行为与 1.7.37 完全一致（默认不影响任何人）
- 文件名已带 `SxxExx` → 以明确标记为准，不换算
- 只对配置里列出的节目生效

## 用法

插件设置 → 基础设置 → 运行设置 → 「期集换算规则」，每行一条：

```
现在就出发 = 2
某综艺 = 3
```

- `= 2`：每期分上下两集（上=奇数集、下=偶数集）
- `= 1`：期号就是集号（等价于不配，但写出来更明确）
- 留空：不换算

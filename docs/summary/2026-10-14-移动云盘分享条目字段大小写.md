# 复盘：移动云盘「预览弹窗打开了，但目录是空的」（1.6.41）

> 任务书：[../plan/2026-10-14-移动云盘分享条目字段大小写.md](../plan/2026-10-14-移动云盘分享条目字段大小写.md)
> 验收：[../test/2026-10-14-移动云盘分享条目字段大小写回归单测.md](../test/2026-10-14-移动云盘分享条目字段大小写回归单测.md)
> 上游：1.6.39（搜得到）→ 1.6.40（预览不再报类型错）→ **1.6.41（目录/文件终于读得出来）**

## 一句话

移动云盘分享接口返回的条目字段是 `caID` / `coID`（大写 D），插件读的是 `caId` / `coId`（小写 d），
取不到节点 ID 的条目被判成无效全部丢弃 —— 预览恒空、转存恒「没有可转存的文件」。
**这条链路从落地起就没成功读过一次目录**，前面两次修复（类型键、域名识别）只是把挡在前面的墙拆掉，
露出了后面这堵更早的墙。

## 为什么会漏掉

1. **没有真机数据打底**：`drive/yun139/share.py` 的字段名是照着「接口大概长这样」写的，
   没有一份线上真实响应做过对照。同一文件里 `coSize`、`udTime`、`caName` 都对，
   偏偏 ID 字段差了大小写 —— 这种错只有拿真响应比一遍才能发现。
2. **错误被静默吞掉**：`_share_node` 遇到缺 ID 就 `return None`，`list_share_directory`
   只把 None 过滤掉，接口层于是返回 `success: true, count: 0`。
   用户看到的是「当前目录为空或未解析到文件」，而不是任何错误信息 ——
   **「空」和「失败」在 UI 上长得一样**，定位只能靠直连接口实测。
3. **前两次修复的验收口径停在「不报错」**：1.6.40 的验收标准是「预览不再返回『资源链接格式或类型无效』」，
   只要不报错就算过；没有要求「必须列出真实条目」。修一层验一层，反而让下一层的静默失败显得像新 bug。

## 关键做法（值得复用）

- **直连接口实测**：写一个只读探针脚本，复刻插件的加解密与请求头（`/tmp/y139_probe.py`），
  在站外就能拿到原始响应结构 —— 比在插件里加日志、发版、再让用户复现快一个数量级。
  这次从「用户说还是」到「根因确证」只用了 4 次请求。
- **fixtures 用真实键名**：新测试的 `ROOT_RESPONSE` / `SUB_RESPONSE` 逐字取自实测响应
  （含 `caID`、`coID`、`coSize`、`udTime`、`null` 字段），旧代码上 8 例里 6 例必失败
  （`AssertionError: 0 != 1 : []`，正是线上症状）。
- **顺手把静默点变成可见点**：`_list_node` 现在把信封 `data.lkName` 记到 `_share_title`，
  分享校验不再恒返回空分享名（同一类「字段在信封上、条目里没有」的假设错误）。

## 遗留与风险

- **转存的下载地址解析未验证**：`dlFromOutLinkV3` 绑定登录账号会话/IP，
  从本容器调用返回 `resultCode=200000401「IP鉴权失败、用户账号鉴权失败」`，
  只能在 MoviePilot 机器上验证。本次只保证「文件列表读得出来」，转存是否通要等真机结果。
- **大小写兼容分支不能删**：线上是大写 D，但历史接口用小写 d，两个都留着（`_entry_value` 按顺序取）。
- **同类隐患**：该驱动其它接口（`getContentInfoFromOutLink` 的 `contentInfo`、`dlFromOutLinkV3` 的 `extInfo`）
  的字段名同样是「照文档写的」，未与真实响应对照过。若转存报「未返回下载地址」，优先怀疑这里。

## 教训

1. **字段名必须用线上真实响应回填**，尤其是 ID/大小写这种「错一个字母就全盘静默」的位置。
2. **`success: true` + 空列表是最危险的失败形态**：它同时骗过调用方、日志和 UI，
   验收标准要写成「列出 N 条真实条目」，而不是「不报错」。
3. **修一层要重新问一次「用户真正想做什么」**：用户的目标是「预览能看、转存能用」，
   不是「预览不报错」。1.6.40 的验收如果多问一句「弹窗里有内容吗」，这个 bug 当天就能一起修掉。
4. **同进程多测试文件的桩会互相顶掉**（`unittest discover` 先全部导入、后执行），
   后导入的注册结果对所有人生效 —— 占位包要用「属性自动返回 Mock」的形式，
   本次首版测试因此把 `test_yun139_caiyun_share` 的三例打成 ERROR，已修。

# 频道监控画质偏好（1.7.14）

日期：2026-10-20
状态：已完成

## 决策

用户拍板三项：

1. **优先可回退**：同一次扫描里同集有多条候选时，先转最优画质；低画质保留 `pending` 作为兜底，最优转存失败下一轮自动回退。
2. **全局一套**：分辨率、HDR、编码、优先字幕组只维护一份配置，所有频道共用。
3. **默认放行**：识别不到画质的资源不参与排序、不拦截、不空等，按原逻辑立即转存。

不做硬门槛，不因为画质低而拒绝转存；也不为了等更高画质让所有资源无限期停在队列里。

## 实现

- 新增 `plugins.v2/cloudsubscribex/core/tg_quality.py`
  - 解析分辨率：`2160P/UHD → 4K`、`FHD → 1080P`、8K/720P/480P。
  - 解析 HDR：`DoVi/DV → DOLBY VISION`，支持 HDR10+/HDR10/HDR/SDR。
  - 解析编码：`H.265/x265 → HEVC`、`H.264/x264 → AVC`、AV1。
  - 解析音频标签用于展示；优先组按标题包含匹配。
  - 无分辨率标签时 `rankable=False`，默认放行。
- `tg_monitor._select_quality_candidates` 按 `(订阅, 季, 集)` 分组，电影按订阅分组；只比较有分辨率的候选。
- 最优候选先转；其余条目标 `match_status=pending`，原因写“同集有更优画质优先…本条保留兜底”。
- 最优失败时下一轮只剩低画质候选，自动按普通流程转存，实现回退。
- 频道监控页在标题下显示画质标签（如 `4K.HDR10.HEVC`）。
- 配置页新增「画质偏好（全局）」：启用开关、分辨率优先级、编码优先级、HDR 优先级、优先字幕组/压制组。

## 限制

- 只在**同一次扫描的候选集**内比较，不跨扫描等待更高画质。低画质先到且没有同批更高画质时，仍会立即转存。
- 剧集整包没有集号时不参与同集比较，避免整季包和单集互抢。
- 优先组只做优先，不做排除。

## 升级验证

1. MoviePilot 插件页升级到 **1.7.14**，重启容器。
2. 配置 → 频道监控 → 画质偏好（全局），确认默认值：
   - 分辨率：`4K,1080P,720P`
   - 编码：`HEVC,AVC,AV1`
   - HDR：`DOLBY VISION,HDR10+,HDR10,HDR,SDR`
3. 让同一剧同集出现 4K 与 1080P 两条资源，点「立即扫描」：应只先转 4K，1080P 显示“待处理 / 同集有更优画质优先…”。
4. 如果 4K 转存失败，下一轮扫描应自动转 1080P（兜底）。
5. 标题没有分辨率标签的资源应照旧立即转存，不被画质偏好拦住。

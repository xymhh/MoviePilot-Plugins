> 日期：2026-11-05 ｜ 状态：已完成 ｜ 版本：1.9.44 → 1.9.45 → 1.9.46 → 1.9.47

## 用户诉求

1. 去掉「未转存账本」，留着没用；
2. 「转存台账」改名为「历史记录」；
3. 添加失败原因（例如秒传失败）；
4. 来源不要显示「手动添加」，显示 TG 频道。

## 1.9.50 修复：打开插件报 Not Found

原因：1.9.49 前端会异步 POST `/api/v1/plugin/CloudSubscribeX/aired_counts`，但 `core/api/registration.py` 的显式 API 列表没有注册该路径，MoviePilot 直接返回 404，宿主把错误弹成「notfound」。

修复：在 `get_api()` 中补注册 `POST /aired_counts`（bear 鉴权，批量查询已播集数与最新开播日期）。插件页不再因该请求报错，已播与开播日期仍会异步补齐。

验证：`python3 -m py_compile core/api/registration.py` 通过；`package.v2.json` 版本号同步为 1.9.50。

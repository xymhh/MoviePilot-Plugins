# 历史记录页改造（1.9.45）

> 日期：2026-11-05 ｜ 状态：已完成 ｜ 版本：1.9.44 → 1.9.45

## 用户诉求

1. 去掉「未转存账本」，留着没用；
2. 「转存台账」改名为「历史记录」；
3. 添加失败原因（例如秒传失败）；
4. 来源不要显示「手动添加」，显示 TG 频道。

## 改动

| 项 | 改动 |
| --- | --- |
| 未转存账本 | 删除历史页工具栏入口、全局/单剧弹窗、`CandidateLedgerPanel.vue` 组件及 `AppPage.vue` 的无用 import；后端账本接口与写账本逻辑保留（频道监控仍在用） |
| 页签 | `AppPage.vue` 的 `history` 页签文案「转存台账」→「历史记录」 |
| 失败原因 | 后端 `prepare_history_group` 新增 `failure_reasons`（原始原因优先，缺原因用 `failure_label`，再缺记「未记录原因」）；前端分组汇总显示「原因 ×N」，明细表新增「失败原因」列，移动端行内显示「失败原因：…」 |
| 来源 | `HistoryRepository._source` 识别 `discovered_via=tg:*` 的 manual 记录为 `tg`；新增启动时幂等回填 `repair_tg_sources`；`prepare_history_group` 同步归一化；前端来源字典补 `tg = TG频道` |

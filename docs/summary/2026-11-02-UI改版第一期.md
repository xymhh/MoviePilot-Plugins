# UI 改版第一期：内容优先风格（1.9.28）

> 日期：2026-11-02　版本：1.9.28　提交：`9e9f067`
> 基线截图：`docs/test/ui-2026-11-02-baseline/`（改版前，真机三页）

## 决策背景

用户对现有界面「大部分都不满意」，在两种风格中选定 **B 内容优先**：海报大、留白多、信息少而精，参考流媒体首页。

诊断结论（详见上一轮真机截图分析）：问题不是组件丑，是「所有东西一样重」——配色发散（128 处硬编码 hex、三套绿、三套紫）、信息不筛（卡片 7 条 / 表格 7 列）、层级缺失（危险操作与普通操作同权重）。

## 本期改了两个组件

### 1. `StatsGrid.vue` — 统计卡降噪

| 旧 | 新 |
| --- | --- |
| 渐变底 + 顶部流光条 + 彩色圆点 + 彩色渐变图标盒 + hover 彩色阴影 | 中性底 + 1px 描边 + 左侧 2px 状态竖条 |
| 四张卡四种色底（紫/蓝/绿/红），「失败 9」最抢眼 | 数字 1.75rem 为主角；仅成功绿、失败红着色；**失败为 0 时自动转灰** |
| 图标占 38×38 | 移除图标 |

改完的效果：眼睛先看到数字，再看到标签；失败归零时整张卡不再喊话。

### 2. `MediaHub.vue` — 追更工作台卡片

| 维度 | 旧 | 新 |
| --- | --- | --- |
| 海报 | 80×116 | **112×162** |
| 卡片内边距 | 12px | 16px |
| 网格间距 | 16px（minmax 330px） | 20px（minmax 360px） |
| 卡片信息 | 7 条：海报 / 标题 / 年份 / 季 chip / 「已入库 0/12」/ 进度条 / 「待补齐 12 集」/ 「频道雷达+搜源」chip / 缺集 chip / 精确到秒的时间 / 分集矩阵按钮 | **4 层**：海报 / 标题 + 副信息（年份 · 第N季）/ 进度（`0 / 12 集` + 状态 + 3px 进度条）/ 相对时间 |
| 恒定信息 | 「频道雷达+搜源」常驻 chip | 删除（对用户无决策价值） |
| 冗余按钮 | 卡片右下「分集矩阵」 | 删除（整卡可点，进抽屉自然见到矩阵） |
| 重复文案 | 「尚未入库」+「未入库」同屏 | 合并为「待入库」 |
| 时间 | `更新于 2026-11-02 11:15:32` | `今天 11:15` / `昨天` / `3 天前`；完整时间保留在 `title` |

状态文案统一为两档：电影 `已入库 / 待入库`，剧集 `缺 E107-E110 / 已齐`。

# 追更日历落地总结（v1.9.56）

> 日期：2026-11-06　提交：`d2ce057`（功能）+ `4bbc4c0`（单测清理）

## 做了什么

1. **后端零成本扩展**：`core/api/page.py:_aired_episode_info` 原本已拿到整季（含未来集）却 `continue` 丢弃未来集。现在同一循环里按 `today < air_date ≤ today+30d` 收集 `upcoming: [{episode, air_date}]`，随 `_AIRED_INFO_CACHE` 6h 缓存，经 `api_vue_aired_counts` 的 `upcoming` 字段透出（缓存命中分支也带出）。
2. **前端**：`usePageData.js` 把 `upcoming` 合并为每张卡的 `upcoming_episodes`；`MediaHub.vue` 顶部新增「追更日历」7 天横条（今天 + 后 6 天，显示每天待更新部数，0 部置灰），点某天按 `air_date` 精确筛选，再点取消；当天有更新的卡片在「最新一集」行前加蓝色 `今日 E05` 标记。
3. **单测** 3 例，CI Test/Lint 双绿，Release 1.9.56 已生成。

## 决策与取舍

- **只用 TMDB**：TVmaze/AniList 能给钟点但覆盖率低（律界战争这类国剧无条目），豆瓣接口 403；TMDB 只到日期。因此日历只回答「哪天播」，不显示时间，不编造。
- **30 天窗口**：覆盖 7 天横条需求且限制 payload；未来更远的集不取。
- **不做独立日历页、不做全月日历**：81 部剧的月历信息密度低，横条 + 筛选两步即可。
- **筛选是叠加的**：日历选天与「有缺集/已入库/正在转存」可组合，不互相清空。

# 同步作业 done 回查单测（P2a / 1.7.19）

日期：2026-10-20。版本：1.7.19（本地验证）。设计见 [ADR](../plan/2026-10-20-同步作业状态机与幂等改造.md#66-p2a-落地记录2026-10-20)。

## 验证目标

1. `done` 作业在复用前必须回查目标文件。
2. 文件存在且大小/文件 ID 匹配 → 复用，不重新转存。
3. 确认文件被删除 → `done -> queued`，清空结果字段、`attempt=0`，本次继续 claim。
4. 同名文件大小/ID 不一致 → `done -> needs_attention`，不覆盖、不重传。
5. 目录/列表查询失败 → 不复用也不重传，避免把网络错误当成文件丢失。
6. 重开/转待处理必须带 `updated_at` CAS，旧观察不能改写别人刚完成的新结果。

## 覆盖的用例

| 用例 | 断言 |
| --- | --- |
| `test_done_exists_is_reused_after_verification` | 回查 exists → `reused=True`，不再调用转存 |
| `test_done_missing_reopens_and_claims` | 回查 missing → 本次拿到新租约，`state=transferring`、`attempt=1`、结果字段清空 |
| `test_done_unknown_does_not_reuse_or_retransfer` | 回查 unknown → `lease=None`，作业仍为 done，不重新转存 |
| `test_done_mismatch_marks_needs_attention` | 回查 mismatch → `needs_attention`，`last_error` 含「不一致」 |
| `test_done_verifier_exception_does_not_reuse` | 回查抛异常 → 不复用、不重传，状态仍为 done |
| `test_reopen_done_requires_observed_version` | 错误的 `expected_updated_at` 重开失败；正确版本才 `done -> queued` |
| `test_done_verifier_reports_exists_and_mismatch` | 服务层按目录列表精确匹配，大小不一致返回 mismatch |
| `test_done_verifier_reports_missing_and_unknown` | 空目录返回 missing，目录未确认返回 unknown |

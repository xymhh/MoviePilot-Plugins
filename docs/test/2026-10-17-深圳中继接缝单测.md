# 深圳中继接缝单测（1.6.55）

> 状态：已通过 2026-10-17

## 改了什么

- 新增 `core/relay.py`：`RelayClient`（`POST /jobs`、`GET /jobs/{id}`、`DELETE /jobs/{id}`，`X-Token` 鉴权）。
- `core/transfer.py`：`CrossTransferTaskManager` 新增 `relay_client / relay_max_bytes / relay_timeout_seconds / relay_fallback_local`。
  - 115 秒传**先探测后下载**分支的触发条件从 `abort` 模式扩为 `abort or relay_active`。
  - 探测确认未命中时：中继可用则调用 `_relay_transfer`；成功即返回，失败按 `relay_fallback_local` 回落本机或抛错。
  - 只对 `source_provider=quark`、无本地文件、`sha1` 校验和、大小 ≤ 上限且目标支持 `FILE_QUERY` 的任务生效。
- `core/drive_manager.py`：开关打开且地址/令牌齐全时构造 `RelayClient` 并注入；否则 `relay_client=None`，链路与 1.6.54 完全一致。
- 版本号 1.6.55；未开启开关时行为逐字节不变（原有 499 例测试全过）。

## 证据

```
pytest tests/test_cross_transfer_relay.py -q   → 4 passed
pytest tests -q                                → 499 passed, 2 failed（test_checkin_days 两例既有 p115client 环境失败）

```

新增用例覆盖：
1. 中继成功 → 返回 True、`method="relay"`、查回目标文件；
2. 中继任务失败 → 回落本机（False）；
3. 中继提交异常 → 回落本机（False）；
4. `relay_fallback_local=False` → 抛 `RuntimeError`，不静默降级。

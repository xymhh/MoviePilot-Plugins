## 2. 决策接入（`tests/test_episode_dedup.py::QualityPreferDecisionTests`，8 条）

- 分辨率提升 → `replace`，理由含「按体积择优：分辨率 720p → 1080p」
- 分辨率下降 → `skip`，理由含「现有版本更优…低于现有 2160p」
- 同分辨率小增益 → `skip`（体积增益不足）
- 同分辨率 +40% → `replace`
- 旧文件名已符合重命名模板 + `quality_ignore_rename_template=true` → 仍然 `replace`（证明绕过模板拦截）
- `quality_ignore_rename_template=false` → `skip`（保留模板版本）
- 总开关关闭 → 理由里不再出现「按体积择优 / 现有版本更优」，回到 1.7.87 逻辑
- 文件名无分辨率 → 纯体积比较仍能 `replace`

> 需求（用户原话）：「我的要求就是电影需要显示已入库，剧集类显示完整/缺集」
> 现象（用户原话）：「只有流行趋势页面的海报角标正确，别的页面要么不显示，要么全部显示缺集」

## 1. 结论

不是"正常"，是缺陷。角标依赖「榜单条目 ↔ 媒体库」的 ID 匹配，而除 TMDB 榜单外的几个源
（豆瓣 / Bangumi / AniList）此前**根本没有走到匹配**，于是：

| 榜单页 | 来源 | 修复前表现 | 原因 |
| --- | --- | --- | --- |
| 流行趋势 | TMDB | 正确 | 条目自带 `tmdb_id`，媒体库按 TMDB 匹配得到 |
| 正在热映 / 热门电影 | 豆瓣电影 | 无角标 | 电影不进剧集分支（"缺集"对电影无意义）；但"已入库"也出不来（无 tmdb_id） |
| 热门剧集 | 豆瓣剧集 | 整页「缺集」 | 条目只有 `douban_id`，媒体库无同源条目 → 匹配为空 → 被算成"缺集" |
| 每日放送 | Bangumi | 整页「缺集」 | 同上（只有 `bangumi_id`） |
| 本季新番 | AniList | 整页「缺集」 | 只有 `anilist_id`，且匹配池**完全不看 anilist_id** → 必然 0 匹配 |

## 2. 源码证据

1. 前端榜单请求不带身份补全：`frontend/cloudsubscribe/src/composables/useMediaData.js:159`
   只传 `source/page/count`（可带 `force`）。
2. 后端默认不补身份：`plugins.v2/cloudsubscribe/core/api/page.py` 的
   `api_vue_resource_recommend(..., resolve_identity: bool = False)`；补身份块靠它启动。
3. 各源条目只有原生 ID：MoviePilot V3 侧 `app/domain/projection/douban.py`（只写 `douban_id`）、
   `app/domain/projection/anilist.py`（只写 `anilist_id` + `anidb_id`）、`bangumi.py`（`bangumi_id`）。
4. 匹配池只认三种 ID：`page.py`「按 TMDB、豆瓣、Bangumi 联合检索」；豆瓣/Bangumi 分支还要求
   媒体库条目 `MediaServerItem.media_source` 与来源同源
   （`core/api/media_library.py`：douban 段 / bangumi 段）→ Emby/Plex 走 TMDB 识别时这些查询恒空。
5. 匹配为空 = 缺集：`page.py` 剧集分支里 `seasons_dict` 空 → 季 1 全库标 `in_library=False`
   → `has_missing_episodes = True`。
6. 官方总集数是死代码：`page.py` 读 `media_item.pop("_rec_seasons")` / `_rec_total_episodes`，
   但**全插件没有任何地方写这两个字段**（`grep -rn "_rec_seasons\|_rec_total_episodes"` 仅命中这一处）
   → 每季集数只能按"库内最大集号"推 → **缺尾季/缺尾集反而显示完整**。
7. 前端只有「缺集」一种状态，且「已入库」对剧集也显示：
   `frontend/cloudsubscribe/src/components/resource/MediaGrid.vue`（入库徽章 + 缺集徽章）。

## 3. 改动（commit `39daa78`）

- `frontend/cloudsubscribe/src/composables/useMediaData.js`：榜单请求加 `resolve_identity=true`
  → 豆瓣/Bangumi/AniList 条目由后端识别链补齐 TMDB 身份后再匹配媒体库。
- `core/api/page.py`：
  - 条目构造时注入 `_rec_seasons` / `_rec_total_episodes`（来源：`seasons` / `number_of_episodes`
    / `total_episodes` / `episodes_count`），识别链结果也回填这两个字段；
  - 已有 `tmdb_id` 的条目跳过识别（TMDB 榜单本身无需二次识别，省请求）；
  - 缺集判定加官方总集数兜底：`library_episodes_total < official_total_eps` → 缺集
    （季 0/specials 不计入官方总集数）；
  - 非剧集分支弹出临时字段，不下发前端。
- `frontend/.../MediaGrid.vue`：电影 = 「已入库」；剧集 = 「完整」(绿 `complete-badge`) /
  「缺集」(琥珀 `missing-badge`) 二值。
- 版本声明：`plugins.v2/cloudsubscribe/__init__.py`、`package.v2.json`（含 history）→ 1.6.23。

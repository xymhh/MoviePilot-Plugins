# 2026-10-19 频道监控两种模式（全部消息 / 全部订阅）单测

对应计划：`docs/plan/2026-10-18-TG频道监控.md`（每频道规则）

## 行为定义（1.6.79）

- `monitor_mode = messages`（默认）：收录频道内所有带链接消息，不做订阅匹配、不自动转存。
- `monitor_mode = subscriptions`：收录后按标题在**全部订阅**内动态匹配，新增订阅自动生效；只有唯一高置信结果才自动转存，多个相近候选留在列表里手动选择。
- 关键词 / 排除词是采集层过滤，与模式取交集（与）。
- 多选订阅白名单与「指定订阅」已移除；旧配置迁移：`auto_transfer=true` → `subscriptions`，其余 → `messages`。
- 1.6.78 曾把「全部」实现成「全部订阅」，1.6.79 修正，`auto_transfer_mode` 字段废弃。

## 覆盖

`tests/test_tg_monitor.py`：

1. `test_monitor_mode_mapping`：显式 `monitor_mode` 保留；旧 `auto_transfer=True/False` 正确推断；`auto_transfer` 字段与模式保持一致。
2. `test_subscriptions_mode_matches_any_subscription`：无白名单、provider 提供 1 条订阅时完成匹配并转存（`transferred`）。
3. `test_auto_transfer_marks_item_and_reports_failure`：两条标题分别匹配 id 7 / id 9，7 成功、9 失败并记录 `auto_transfer_error`。
4. `test_provider_matches_title_and_leaves_ambiguity_pending`：两个同名同季订阅 → 留待手动；换成唯一订阅 → 自动转存。

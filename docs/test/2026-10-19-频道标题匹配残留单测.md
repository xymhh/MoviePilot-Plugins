# 频道标题清洗残留导致「匹配度过低（88）」单测（2026-10-19）

## 现象（真机日志）

```
14:05:39 嫁金钗(2026)4k WEB-DL.DoVi 2160p 杜比视界 简体字幕 第10集 / 匹配度过低（88）
14:15:42 《玉簟秋》2026 更新至 - 第 15 集 - [1080p] [AAC 2.0] [丞磊 徐若晗 王丽坤] … / 匹配度过低（88）
14:25:46 玉簟秋(2026)web-4k H265 ACC简体字幕 第15集 / 匹配度过低（88）
```

订阅均为精确名（`玉簟秋` #137、`嫁金钗` #158），阈值 90，前缀匹配固定 88 → 永远差 2 分。

## 根因

`parse_message_title` 清洗只删除已收录的质量词，不删括号内容；`DoVi`/`ACC`/`web`/`2.0`
等未收录后缀残留在标题里：

- `玉簟秋 web- ACC` → `玉簟秋webacc`
- `嫁金钗 .DoVi` → `嫁金钗dovi`
- 演员/分类括号内容 → `玉簟秋20丞磊徐若晗王丽坤民国虐恋家国`

精确匹配因此退化为「标题前缀」（88 分）。

## 修复

`core/tg_match.py`：

1. 新增 `_BRACKET_RE`：清洗阶段整段删除 `[]`/`【】`/`()`/`（）` 内容（季/集/年份此前已提取，不受影响）。
2. 质量词补 `DoVi`、`WEB`、`HDTV`、`ACC`、`CHS`、`CHT`、`简英`、`双语`、`内封`。
3. 新增 `_TECH_RESIDUE_RE`：只在中文/数字之后、循环剥离尾部技术词与分隔符（英文片名如 `Web of Lies` 不受伤）。
4. `match_item` 无候选时区分「标题匹配但季号不符」，日志直接写消息季号与订阅季号。

## 验证


真实标题解析结果：`玉簟秋`、`玉簟秋`、`嫁金钗`，分数 100，`matched` 非空。

## 结论

阈值不降（避免 `Doctor` 误吞 `Doctor Who`）；问题在清洗而非打分。1.6.80 发布。

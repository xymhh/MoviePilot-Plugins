## 2. 新卡点：115 秒传未命中即中止

```
12:01:57 service.py 跨盘转存失败：夸克网盘 -> 115网盘，阶段=aborted，
         原因=未命中秒传，已按设置中止（未上传任何数据）
12:01:57 target_writer.py 目标写入not_written：... size=0 reason=写入方未写入
```

配置：`cross_transfer_rapid_miss_action = 'abort'`（另有 `cross_transfer_relay_enabled=False`、`cross_transfer_relay_always=False`、`cross_transfer_relay_fallback_local=False`）。

后果：115 侧没有这些 4K 文件的相同内容 → 秒传必然不命中 → 一次下载/上传都不做，洗版对大体积高清源永久失效。3GB 以下的 1080p 源如果之前秒传命中过，才会「看起来能洗」。

可选做法：

1. `rapid_miss_action=fallback` + `cross_transfer_download_threads=4`：未命中就本机分段下载再上传 115（4 集约 20.7GB，双向流量，按 10MB/s 粗估 35 分钟下载 + 上传时间）。
2. 打开中继（`cross_transfer_relay_enabled=True`）：交给远程中继下载再回传，需确认中继可用与额度。
3. 保持 abort：等于接受「4K 永远进不来」，洗版只对能秒传的源有效。

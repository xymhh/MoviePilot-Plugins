## 1. 改动清单

| 文件 | 改动 |
| --- | --- |
| `plugins.v3/p115strmhelper/helper/transfer/handler.py` | 新增 `QUALITY_BETTER_SKIP_REASON` 常量；`_batch_move_or_copy` 返回 `(失败, 跳过, 成功)`；两处跳过裁决改走 `task_skips`；`process_batch` 三类解包 + 汇总日志加「跳过」；新增 `_batch_record_skips` / `_record_skip` |

| `plugins.v3/p115strmhelper/version.py` / `package.v3.json` | 2.7.25 → 2.7.26 + 更新说明 |

行为要点：

1. 命中「媒体库存在同名文件，且质量更好」或「覆盖模式为不覆盖」时**不写任何整理历史**（不调 `add_transfer_fail` / `add_transfer_success`）、不发 `TransferFailed` 事件、不登记智能体重试 —— 原成功记录不再被同源唯一索引 replace 成失败。
2. 仅当原因是「质量更好」时才删除低质量源文件（`StorageChain().delete_media_file(fileitem=...)`）。
   **覆盖模式=never 与第三方插件拒绝覆盖的跳过不删源文件**（无法确认库内更优，避免误删更好版本），只记日志与通知。
3. 插件通知受 `configer.notify` 控制，文案为「【整理接管】已跳过（库内已有更优文件）」。

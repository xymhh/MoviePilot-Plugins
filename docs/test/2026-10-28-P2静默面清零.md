# 2026-10-28 P2：静默失败面清零 + 棘轮归零（1.7.94）

> 承接 [P1-A](2026-10-28-P1-A死键与静默面收口.md)。P1-A 只清了四条主链路（64 处），本轮把全包清完并让 CI 顶住。

## 1. 做了什么

AST 口径统计「静默 except」两类：

| 形态 | 含义 | 本轮前 | 本轮后 |
| --- | --- | --- | --- |
| `except` 块体只有 `pass` | 失败完全消失，连一行日志都没有 | 87 | **0** |
| `except` 块体只有 `logger.debug(...)` 且无 `exc_info` | 只看到 `str(e)`，不知道在哪炸的 | 77 | **0** |

全部改为 `logger.debug("<函数名> 分支忽略异常", exc_info=True)` / 补 `exc_info=True`，覆盖 **60 个文件、164 处**。
11 个原本没有 logger 的模块（`core/relay.py`、`core/media.py`、`handlers/sync/utils.py`、`drive/guangya/oss.py`、
`search/hdhive/*`、`search/seedhub/security.py`、`search/pianku/service.py`、`core/subscribe/provider.py` 等）
补了 `from app.log import logger`。

**行为不变**：默认日志级别下不产生任何新输出（`debug` 默认不打印）；只有把日志调到 DEBUG 时，才从「一句话」变成「一句话 + 异常栈」。上一轮已经用 `warning` 报的强感知失败点（STRM 写盘失败、树构建失败等）没有动。

## 2. 棘轮归零

`scripts/lint.py`：

```python
SILENT_PASS_BUDGET = 0
SILENT_DEBUG_BUDGET = 0
```

- 任何新增静默点 → `lint.py --all` 直接 ERROR，CI 红。
- 逃生口：确实必须完全静默（探测性 import 之类）时，在该 `except` 行尾写 `# noqa: silent`，统计跳过。

反证（手工验证，未入库）：

```
新增一个 except: pass        → except:pass=1（预算 0）→ 1 error
同一处加 # noqa: silent      → except:pass=0（预算 0）→ 0 error
```

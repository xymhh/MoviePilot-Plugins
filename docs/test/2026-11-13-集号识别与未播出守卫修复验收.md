## 真因（本地实测，非推测）

用 `utils/share_recognize.py:build_plan` 喂 preview 实测的真实文件树
（3 个画质组各 `01.mkv`…`13.mkv` + 根目录 `14.mkv` / `14 DV.mkv`）：

| 检查 | 结果 |
| --- | --- |
| `build_plan` | `status=ready`、`selected` **14 个**、含 `M 坆螝战爭/14 DV.mkv`、`filled_from={14: ''}` → 识别计划选中 E14。 |
| `classify_path('14 DV.mkv')` | `ep=14`（「开头数字 + 空格 + 画质词」口径）。 |
| `_tail_episode_from_name('14 DV.mkv')` | `None`（只认末尾紧贴数字）。 |
| `rescue_tail_episodes_from_names(13 集 + 14 DV.mkv)` | `{1..13}`，**不含 14**；换成 `14.mkv` 则 `{1..14}`。 |

链路：`_summarize_share_episodes` 用 `FileMatcher.episode_from_file`，`14 DV.mkv` 认不出 →
`episodes` 已非空（1..13），原代码 `if not episodes` 才兜底 → E14 凭空消失 →
`missing_episode_set({14}) ∩ share_episodes({1..13}) = ∅` → `episodes_to_match` 空 → 0 转存。
候选账本 7 条 `集号不符 · 有 E01-E13，缺 E14` 佐证。

独立缺陷 B：`跳过未播出剧集：E05、E15-E25（其中 11 集 TMDB 无播出日期）` —— 库里明明有 E05
却被判未播出、订阅 `note=[1,2,3,4,6..13]` 里 E05 被剔除（`_reconcile_subscribe_physical_episodes`
以「Emby+115 实际数据」纠正订阅进度）。TMDB 分集日期错位，物理事实应优先。

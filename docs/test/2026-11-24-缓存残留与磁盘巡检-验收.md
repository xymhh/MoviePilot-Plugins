2. **行为边界**（每条一个用例）：超期才删 / 未超期保留 / `active_names` 保留 /
   `.aria2` 伴随文件保留 / 非视频扩展名（`.ass` `.txt` `.zip`）不动 /

## 三、P1 磁盘巡检：证据

`CacheWatchService.check()` 六个用例：超阈值发一条通知 / 同状态冷却期内不重发 /
恢复后发恢复通知（第 2 条）/ 首次正常不打扰 / 缓存目录不存在不抛异常 /
分区剩余 <15% 也能单独触发 warn。

阈值与冷却为模块常量（`CACHE_DIR_ALERT_BYTES=20GB`、`DISK_FREE_ALERT_RATIO=0.15`、
`ALERT_COOLDOWN_SECONDS=12h`），状态落 `<插件数据目录>/cache_watch_state.json`，
读写失败只降级不去重，不影响巡检结论。

调度：`core/api/registration.py::_maintenance_services` 新增
`CloudSubscribe_CacheWatch`（`IntervalTrigger(hours=6)`），入口
`_run_scheduled_task(task="cache_watch")`，异常交 MP 记 ERROR。

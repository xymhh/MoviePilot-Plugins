## 2. 关键实现口径

- **递归到底**：`max_depth=MAX_DEPTH(32)`，不传 `target_season`；驱动不支持该参数（夸克本来就是全递归）时自动退回无参调用。
- **不许半棵树冒充全量**：异常 → `reason=SCAN_FAILED`；空结果 → `reason=EMPTY`；两种情况 `complete=False`。
- **TMDB 只给集数**：`season_total()` 拿不到就返回 `None`，不拿「最大集号」冒充集数。
- **无季号反推季**：只有「某一季的集数区间能完整容纳全部集号」才反推；能容纳的季不止一个且集数相同 → 不猜，返回 `None`。
- **影子识别**：整棵树算一次计划，只打日志，任何异常只写 debug，不影响转存。

日志样例（真实转存时会出现）：

```
影子识别[ready] 文件 114 / 主版本 4K DV杜比视界 高码率（30 集+补齐） / 缺 0 - 嫁金钗 2160p
```

## 5. M2-4：转存接管（剧集路径）

`_validated_resource_files()` 列完树后调用 `_apply_share_recognition()`：

| 条件 | 行为 |
| --- | --- |
| 手选了文件（`target_file_ids/names`） | 原样返回，人工优先 |
| 没有 TMDB 身份或不知道季号（电影、无季分享） | 原样返回，维持现有管线 |
| 计划 `skip`（无媒体 / 纯压缩包） | 返回空 → 不转存，日志 `识别计划[skip:NO_MEDIA] 不转存` |
| 计划 `review`（无集号 / 身份不明） | 返回空 → 不转存 |
| 计划 `ready` | 只返回 `plan.selected` 里的文件（含同目录字幕），日志 `识别计划[ready] 转 N 个 / 丢 M 个` |
| 计划算出来但路径映射为空 | 保守回退整包 + warning（识别层不许成为新的失败点） |
| 识别过程抛任何异常 | debug 记录后原样返回 |

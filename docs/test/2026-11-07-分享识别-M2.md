## 2. 关键实现口径

- **递归到底**：`max_depth=MAX_DEPTH(32)`，不传 `target_season`；驱动不支持该参数（夸克本来就是全递归）时自动退回无参调用。
- **不许半棵树冒充全量**：异常 → `reason=SCAN_FAILED`；空结果 → `reason=EMPTY`；两种情况 `complete=False`。
- **TMDB 只给集数**：`season_total()` 拿不到就返回 `None`，不拿「最大集号」冒充集数。
- **无季号反推季**：只有「某一季的集数区间能完整容纳全部集号」才反推；能容纳的季不止一个且集数相同 → 不猜，返回 `None`。
- **影子识别**：整棵树算一次计划，只打日志，任何异常只写 debug，不影响转存。

## 2. 等价性校验（硬证据）

```
python3 scripts/verify_split_equivalence.py \
  --allow "SyncHandler._emby_library_refresh=>MediaRefreshMixin._emby_library_refresh" \
  --accept-change TransferOpsMixin._remember_transfer_failure \
  --accept-change TransferOpsMixin._transfer_failure_reason \
  --accept-change TransferOpsMixin._verify_sync_job_result \
  --accept-change TransferOpsMixin._get_sync_job_ledger
```

结果：**完全一致 184 个方法 / 换类但方法体一致 12 个 / 声明式容许改动 4 个 → `[OK]`**
（脚本本次新增两项能力：比对模块级函数；`--accept-change` 声明式放行方法体改动，未声明的一律 FAIL。）

### 4 处改动为什么必须改

拆分后方法运行在**职责组件实例**上，`self.__dict__` 指向组件自己的字典，读不到宿主 `SyncHandler` 的状态。4 处 `self.__dict__` 直读会静默失效：

| 位置 | 原写法 | 后果 | 改法 |
| --- | --- | --- | --- |
| `_verify_sync_job_result` | `self.__dict__.get("_cloud_directories")` | 恒为 `None` → done 回查恒返回 `unknown`，账本复用能力**静默失效** | `getattr(self, "_cloud_directories", None)` |
| `_get_sync_job_ledger` | `self.__dict__.get/set("_sync_job_ledger_instance")` | 实例缓存落在组件私有字典，别处读不到 | 普通属性读写（委托到宿主） |
| `_remember_transfer_failure` | `self.__dict__.setdefault("_transfer_failure_reasons", {})` | 失败原因写进组件私有字典 | 同上，缺失时建 dict 后写宿主 |
| `_transfer_failure_reason` | `self.__dict__.get("_transfer_failure_reasons")` | 与写入口径不一致 | 同上 |

## 3. 顺带修掉的两个线上缺陷（v1.9.20 / v1.9.21 已带出）

### 3.1 职责组件漏继承 `OwnerDelegator` → 线上 TypeError

`core/delegation.py:get_component()` 用 `component_type(owner)` 实例化组件。`MediaRefreshMixin` / `StrmOpsMixin`（v1.9.20、v1.9.21 已发布）当时是裸类，`object.__init__` 不接受参数：

```
TypeError: object() takes no arguments
```

即 `refresh_media_servers` / STRM 重建等入口一旦被调用就抛异常（内层被 except 吞成失败）。v1.9.22 三个类统一改为 `class XxxMixin(OwnerDelegator)`。

### 3.2 `resolve_component` 不校验条目是类 → 调用被替身吞掉

`if hasattr(component_type, name)` 对 Mock/测试替身恒为真，替身会抢在真组件前把调用接管（合并键解析出 `MagicMock` 方法，调用静默返回 MagicMock，转存 0 次）。修法：`core/delegation.py` 加 `if not isinstance(component_type, type): continue`。

### 3.3 测试基建三处修复

1. `tests/plugin_env.py: ensure_package()` 给磁盘上真实存在的插件包绑定真实 `__path__` —— 拆分新增模块后，`from ...utils.file_parser import ...` 不再依赖「别的用例碰巧先注册过」的执行顺序。
2. 新增 `install_core_delegation()`：占位包 `cloudsubscribex.core` 装上真实的 `OwnerDelegator` / `get_component` / `resolve_component`，否则委托解析拿到的是 MagicMock。
3. 新增 `stub_component_method()`：方法搬到职责类后，给宿主赋值同名属性**盖不住类方法**，打桩必须写进组件实例字典。

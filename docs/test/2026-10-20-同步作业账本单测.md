## 结论

- `tests/test_sync_job_ledger.py`：16 例通过。
- 全量 `python -m unittest discover -s tests -p "test_*.py"`：595 项，2 例失败；均为本机未安装 `p115client` 的既有签到用例，与本次改动无关。
- `python scripts/lint.py --all`：635 个文件，0 error / 343 warning（warning 均为既有缩进提示）。

## 覆盖点

| 类别 | 断言 |
| --- | --- |
| 幂等键 | 路径尾斜杠/重复斜杠、文件名首尾空白不影响键；同名不同内容、不同目标盘会改变键；SHA1 大小写归一 |
| 内容身份 | SHA1 → MD5 → 文件 ID+大小降级；非法短哈希不被当成稳定身份 |
| 状态机 | 允许边逐条验证；`queued -> done`、终态回退、未知状态均拒绝 |
| 并发 claim | 同一作业两个 worker 只能一个成功；第二次 claim 失败 |
| 租约 | 过期可回收并重试；重试次数耗尽转 `failed`；心跳只允许持有者 |
| 迁移 | 错误 owner 不能推进状态；完成后写结果字段与 `finished_at` |
| 清理 | 终态作业按 `updated_at` 截止时间删除 |

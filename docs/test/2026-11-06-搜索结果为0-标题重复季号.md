# 搜索结果为 0 的根因：标题里重复季号（1.9.65）

> 状态：已完成 2026-11-06，对应 v1.9.65

## 现象

用户反馈「seedhub 搜索结果一直是 0」。

## 排查

从线上日志抓 `搜索源查询完成` 行（近 1200 行）：

| 媒体串 | PanSou | SeedHub |
| --- | --- | --- |
| 谷雨 (2026) S01 | 50 | 14 |
| 走马上任 (2026) S01 | 50 | 29 |
| 再婚皇后 (2026) S01 | 39 | 6 |
| **谷雨 S01 (2026) S01** | **0** | **0** |
| **假面骑士麦斯 S01 (2026) S01** | **0** | **0** |

规律很清楚：正常进词（`谷雨 (2026) S01`）有结果；标题里已经带 `S01` 的（`谷雨 S01 (2026) S01`）两个渠道都 0。

原因：追更抽屉的默认关键词是「剧名 S01」、按集搜是「剧名 S01E07」（`MediaDrawer.vue` 的 `defaultKeyword()` / `searchEpisode()`），后端把这段当作**纯标题**，搜索时又拼一次 `S{n:02d}`，最终关键词变成「谷雨 S01 S01」→ 各站都搜不到。

线上复现（1.9.64）：

```
POST resource/search_resources {"source":"seedhub","title":"谷雨 S01","season":1}
→ 共检索到 0 条候选资源（渠道：SeedHub｜耗时 3.48s）

POST resource/search_resources {"source":"seedhub","title":"谷雨","season":1}
→ 共检索到 14 条候选资源（渠道：SeedHub｜耗时 5.24s）
```

## 修复

新增 `plugins.v2/cloudsubscribex/core/api/title_parse.py`：

```python
split_title_season("谷雨 S01")      -> ("谷雨", 1)
split_title_season("谷雨 S01E07")   -> ("谷雨", 1)
split_title_season("谷雨 第2季")     -> ("谷雨", 2)
split_title_season("谷雨")           -> ("谷雨", None)
```

`resource/search_resources` 在识别媒体前先剥掉尾部季/集号；若请求没给 `season`，就用剥出来的季号。整串只是季号（如 `S01`）时不清空，避免拿空标题去搜。

## 验证

- 新增 `tests/test_title_season_split.py` 6 例全过。
- `scripts/lint.py --all`：462 文件 0 error。
- 预期修复后 `title="谷雨 S01"` 等价于 `title="谷雨"` → SeedHub 14 条。

## 备注

- 剥掉集号后，「按集搜」只是不再用集号做关键词过滤，候选仍是整季包；这与 1.9.60 观察到的「带集号也只是收窄、仍返回整包」一致。
- 早期 `search/test` 单源测试仍按用户原样输入标题，不做剥离（那是调试入口）。

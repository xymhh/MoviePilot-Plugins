# 运行中任务浮条（v1.9.74）— 非订阅转存进度可见性

## 问题（用户反馈 2026-11-10）

「转存非订阅影视时，看不到进度」。

## 根因（代码走查，非猜测）

| 位置 | 事实 |
| --- | --- |
| `frontend/cloudsubscribex/src/components/AppPageResource.vue` | 全文无 `runtime` / `task` / `progress` 引用 —— 网盘资源页零运行态 UI，转存后只弹 toast |
| `components/dashboard/MediaHub.vue:191-204` | 任务只按 `subscribe_id` 或「标题+季」挂到已有卡片上 |
| `components/AppPage.vue`（改前） | 顶栏只有一行 `runtimeSummary` 文字，无百分比、无任务列表 |
| `docs/summary/2026-11-05-移除任务中心.md` | 1.9.44 删掉任务中心后，独立任务列表入口消失 |

非订阅影视手动转存：`POST /sync/manual` → 临时目标（`_transient_target`，任务 id `media:tmdb_xxx_movie`）→ 任务确实注册进 `_sync_tasks` 并有状态推进，但落地前既没有订阅卡也没有历史卡 → 前端无处挂载 → 用户完全看不到进度。

## 改动

1. 新增 `components/RuntimeTaskStrip.vue`：列出运行中任务（片名/季、状态 chip、阶段文字、已处理文件数、进度条），可收起，超过 4 条折叠提示。
2. 新增 `composables/useRuntimeTasks.js`：读 `/runtime` 快照 + SSE，页面隐藏时断开，SSE 连续失败降级为轮询（10s / 30s）。
3. 挂载到 `AppPage.vue`（追更列表页 header 下方）与 `AppPageResource.vue`（筛选条下方）。
4. 版本 1.9.73 → 1.9.74（本地基线落后于 origin/main，先在 1.9.68 上做，发现远端已到 1.9.73 后 rebase 重做）。

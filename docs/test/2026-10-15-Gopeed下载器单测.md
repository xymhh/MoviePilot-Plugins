## 2. 主 agent 独立复核发现并修掉的 3 处（委派首版有 bug）

按 Gopeed v1.9.3 源码逐条核对 API 契约，委派首版有 3 处与真实接口不符：

| # | 首版写法 | 源码事实 | 后果 | 修法 |
| --- | --- | --- | --- | --- |
| 1 | `info()` 请求 `/api/v1/version` | 无此路由，正确是 `/api/v1/info`（`pkg/rest/server.go:122`） | 探测必 404 | 改路由 |
| 2 | 读 `progress.read` / `progress.total` | `Progress` 只有 `used/speed/downloaded/uploadSpeed/uploaded/extractStatus`（`pkg/download/downloader.go:69-82`）；`Task` 无 `size`，总量在 `task.meta.res.size`（`pkg/download/model.go:23-32`） | 进度回调恒上报 0，进度条永远 0% | 改读 `progress.downloaded`，总量回退 `meta.res.size` → `file_item.size` |
| 3 | 只把 `error` / `removed` 当终态 | 真实状态集 `ready/running/pause/wait/error/done`（`pkg/base/constants.go`），**没有 removed、有 pause** | 任务被外部暂停时轮询永久空转，占住中继并发位 | `pause` 也判为终态失败；另加「零进度 `stall_timeout`（默认 900s）」兜底 |

复核无误、未改的点：

- `DELETE /api/v1/tasks/{id}` 不带 `force=true` 只删任务记录、**保留文件**（`pkg/rest/api.go:155-168`：`force := r.FormValue("force")` → `Downloader.Delete(filter, force=="true")`）—— 完成后清理任务记录安全。
- 请求头字段名正确：`extra.header`（`pkg/protocol/http/model.go` `ReqExtra.Header json:"header"`）。
- 停止语义对齐：内置下载器抛 `InterruptedError`（`core/transfer.py:255,353`），Gopeed 侧用 `GopeedDownloadStopped(InterruptedError, RuntimeError)`；**停止路径不触发回落**（否则内置会重新开始下载）。
- 未设置任务级连接数 `opts.extra.connections`（HTTP 协议支持，见 `pkg/protocol/http/model.go`），用 Gopeed 自身默认值。

## 4. 真机验收清单（待用户执行）

前置：**Gopeed 与 MP 必须把同一宿主目录挂到同一容器路径**（默认无需路径映射）。

```yaml
# Gopeed 的 docker-compose.yml 增加一行（示例：宿主 /volume1/docker/mp-relay → 容器 /relay）
    volumes:
      - /volume1/docker/mp-relay:/relay
```

MP 容器同样把该宿主目录挂到 `/relay`，并把插件「跨盘传输 → 中继目录」设为 `/relay`。

插件设置：外部下载器 = **Gopeed（外部）**；Gopeed 地址 `http://gopeed:9999`（同 `1panel-network` 用容器名即可）；接口令牌 = Gopeed → 设置 → 高级 → 接口令牌；路径前缀映射留空。

验收点：

1. 触发一次夸克 → 115 跨盘：Gopeed 面板出现任务，任务名/目录与中继路径一致；
2. 插件日志无「Gopeed 下载失败，自动回落内置下载器」；完成后 Gopeed 任务记录消失、**文件保留**；
3. 速度对比：同一资源「内置下载器」vs「Gopeed」各跑一次，记录耗时与平均速度（本功能的唯一目的）；
4. 故意把 Token 填错 → 应回落内置、恰好一条 warning，且日志里**没有 token 明文**；
5. 中继文件、上传 115、重命名、通知、历史、STRM 与 1.6.42 表现一致。

## 5. 已知边界

- 只接**夸克**（架构通用，其它源盘后续一行接入）；
- 未暴露任务级连接数配置（用 Gopeed 自身默认），若实测提速不足，下个版本可加 `opts.extra.connections`；
- `preserve_partial=True` 时不删 Gopeed 任务，但 Gopeed 新建任务是否复用旧临时文件未验证（HTTP 单文件场景影响有限）；
- 路径映射只做前缀替换，不做双向校验（配错时表现为找不到文件 → 重试 3 次后回落内置，主链路仍能完成）。

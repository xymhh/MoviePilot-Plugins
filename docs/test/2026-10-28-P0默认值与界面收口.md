# 1.7.92 默认值与界面收口（评审 P0）

日期：2026-10-28
版本：`1.7.92`（评审基线 1.7.91）

## 背景

2026-10-28 对 1.7.91 做了一轮「缺陷与冲突」评审，结论集中在**默认值 / 界面 / 实现三者对不上**，
业务逻辑未发现明确 bug。本次只做 P0（写盘副作用与界面真值），不动业务判定链。

评审里被**撤回**的一条（避免误改）：`cross_transfer_relay_always`（跨盘一律走中继）不是残留开关，
而是 1.7.70 按用户要求新增、带 2 条单测的正式功能（`docs/summary/2026-10-25-跨盘一律走中继开关.md`），
且界面上它的 `show` 依赖 `cross_transfer_relay_enabled`，中继关闭时不可见。本次保留不动。

## 为什么这样改（不是简单翻默认值）

1. **STRM 生成是写盘副作用**：默认开会与 P115StrmHelper 双写同一目录，且每 10 分钟遍历一次 115 目录树。
   订阅助手的默认行为应该是「不写盘」，要写盘由用户显式打开。
2. **默认地址必须自洽**：旧默认 `172.17.0.1:9527` 是别的工具的端口，新装用户开箱即指向不存在的服务。
   改为「留空 + 插件自带端点模板」后，用户只需填 `http://主机:端口`。
3. **静默回退要留痕**：四条旧键（`tg_channels` / `tg_monitor_keywords` / `tg_monitor_exclude_keywords` /
   `tg_monitor_scan_limit`）已无界面入口，但规则为空时仍会展开成频道规则。不改判定，只补 WARNING。

## 4. 顺手修的测试基建缺陷

拆分后 4 个用例报 `ModuleNotFoundError`（`test_movie_offline_sync` / `test_same_source_relay_guard` / `test_sync_transfer_ledger_wiring` / `test_transfer_organize_behavior`）。

根因：`tests/plugin_env.py::_ensure_parents` 创建的占位包 `__path__ = []`，`service.py` 里任何**新增**的 `from .xxx import` 都找不到模块；此前能跑是因为同目录模块恰好被别的用例提前注册进 `sys.modules`（靠测试执行顺序）。

修法：占位包的 `__path__` 指向磁盘上的真实目录（`_bind_real_path`）。修完测试数从 1042 回到 1075，错误数与基线一致。

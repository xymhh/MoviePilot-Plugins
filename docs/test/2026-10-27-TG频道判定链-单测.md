## 2. 新增/改写用例

| 用例 | 断言 |
| --- | --- |
| `test_channel_rules_always_subscriptions` | 旧 `monitor_mode=messages`、`auto_transfer=false` 一律归一化为订阅模式，白名单清空 |
| `test_matched_item_is_queued` | 唯一高置信命中 → `status=queued`、`matched_subscribe_id` 正确、返回待入队列表 |
| `test_unmatched_item_is_ignored` | 未命中 → `status=ignored` / `match_status=unmatched`，统计 `{queued:1, ignored:1, failed:0}` |
| `test_worker_batches_by_subscribe_and_marks_outcome` | 同订阅 2 条 → batch handler 只调 1 次（2 个 id），两条都置 `transferred` |
| `test_worker_marks_skipped_when_no_new_file` | `transferred=0` → `skipped`，消息写入 `auto_transfer_error` |
| `test_queue_cap_ignores_extra_items` | 队列已满 200 → 新命中全部 `ignored`，reason 含「队列积压」 |
| `test_best_quality_queued_lower_ignored` | 同集 2160p/1080p → 只有 2160p 入队，1080p `ignored` 且 reason 含「更优画质」 |
| `test_failed_best_is_reported_not_silently_retried` | 转存失败 → `failed` + 错误信息，不静默降级重试 |
| `test_provider_matches_title_and_ignores_ambiguity` | 同名同季重复登记取 id 更大者；名称近似但不匹配 → `ignored` |

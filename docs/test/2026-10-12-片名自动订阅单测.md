## 2. 新单测覆盖的用例（tests/test_message_title_subscribe.py:1-190）

| 用例 | 断言要点 |
| --- | --- |
| `test_title_payload_accepts_plain_title` | `"  仙逆  "` → 收下并 strip |
| `test_title_payload_rejects_commands_callbacks_and_links` | 13 组拒绝样本：`/search 仙逆`、`CALLBACK:`、带 `callback_data`、115/磁力链接、`仙逆 有吗？`、带图片/文件/语音、`1 2 3 4`、超 40 字、含换行、含 `/` |
| `test_title_payload_disabled` | 开关关 → 不接管 |
| `test_creates_subscribe_and_triggers_search` | 未订阅 → 建订 + `queue_subscribe_search(id, "N")` + 回执含「已创建订阅」「仙逆」 |
| `test_existing_subscribe_only_triggers_search` | 已订阅 → 只 `queue_subscribe_search(7, "R")` + 回执含「已在订阅中」 |
| `test_unrecognized_title_stays_silent` | 识别不出 → 无队列、无回执（消息交回平台） |
| `test_create_failure_reports_reason` | 建订失败 → 回执带平台原因「订阅已存在」 |
| `test_recognize_exception_is_swallowed` | 识别抛异常 → 吞掉、不打扰用户 |
| `test_try_handle_consumes_title_message` | `_try_handle` 返回 True 且后台线程确实执行了建订 |
| `test_try_handle_ignores_non_title_message` | 命令 → False；链接 → True 但仍走链接分支（不产生订阅动作） |
| `test_install_disabled_when_both_switches_off` | 两个开关都关 → hook 不安装（`_handle_message_core` 保持原函数）；只开片名开关 → 安装 |

实现细节备忘：`OwnerDelegator.__setattr__` 会把属性写委托给宿主对象，所以单测里改「类上已定义的方法」必须用 `patch.object(HookClass, ...)`，不能 `hook.method = ...`（否则桩函数被写到宿主上，类方法仍生效）。

## 3. 真机（待用户更新插件后补）

需要 MoviePilot 侧更新 CloudSubscribe 到 1.6.26 后执行，记录在本文档追加节：

- [ ] TG 发片名（如「仙逆」）→ 收到「【网盘订阅】已创建订阅《仙逆》…」回执
- [ ] MoviePilot 订阅列表出现该订阅（类型/季号正确）
- [ ] 插件日志出现该订阅的网盘搜索记录，命中则自动转存入库
- [ ] 再发同一片名 → 回执「已在订阅中，已触发一次网盘资源搜索」
- [ ] 回归：发命令 `/…`、发网盘链接、发问句「仙逆有吗？」行为与 1.6.24 一致

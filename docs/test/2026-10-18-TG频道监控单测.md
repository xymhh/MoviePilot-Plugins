# 2026-10-18 TG 频道监控每频道规则单测

对应计划：`docs/plan/2026-10-18-TG频道监控.md` 的「每频道独立规则」一节。

## 覆盖

`tests/test_tg_monitor.py` 新增 4 例：

1. **规则归一化**：`https://t.me/demo` → `@demo`；同频道重复项去重；空频道丢弃；
   `enabled=False` 保留但停用；关键词支持中文逗号/换行；`scan_limit=999` 截到 200。
2. **旧配置迁移**：`tg_channels=["@a","https://t.me/b"]` + 全局 `keywords/exclude/scan_limit`
   → 展开成两条规则，每条都带同一组关键词与条数。
3. **JSON 字符串**：`tg_channel_rules` 以 JSON 文本保存时也能解析。
4. **两频道独立扫描**（fake Telethon client）：
   - A 频道：包含词 `4K`，回溯 `1` 条 → 只入库最新一条 4K，1080p 被过滤；
   - B 频道：排除词 `广告`，回溯 `2` 条 → 广告条被跳过，普通条入库；
   - 断言传给 `get_messages` 的 `limit` 分别为 `1` / `2`，证明规则没有串用。

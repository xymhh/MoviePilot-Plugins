# 抽屉搜索渠道口径与积分标识（1.9.62）

> 状态：已完成 2026-11-06，对应提交见 v1.9.62

## 问题

线上后台 `search_source_order = ['pansou']`，只启用了 PanSou，但抽屉「搜索资源」返回 106 条候选，其中 HDHive 35 条、Dian115 21 条。

实测（`POST /api/v1/plugin/CloudSubscribeX/resource/search_resources`，吞噬星空 S1 / TMDB 101172）：

| 渠道 | 条数 | url 有值 | 说明 |
| --- | --- | --- | --- |
| pansou | 50 | 50 | 有直链，可转存 |
| hdhive | 35 | 0 | `need_unlock=true`，4–20 积分 |
| dian115 | 21 | 0 | `need_unlock=true`，需解锁 |

后果两条：

1. 后台选择的渠道与搜索结果不一致（用户视角「我明明只开了 PanSou」）；
2. 付费渠道候选 url 为空，点转存只会得到「请填写资源链接或选择网盘路径」，与真实原因（未解锁）无关。

## 根因

`core/api/search.py` 的 `api_vue_resource_search_resources` 用 `handler.get_available_sources_meta()` 取渠道，该函数返回**全部已注册渠道**（注释写着「无需在设置中手动开启即可自动搜索」）。订阅搜索走的是 `get_enabled_sources()`（读 `search_source_order`），两者口径分叉。

## 修复

1. 新增 `core/api/source_filter.py::filter_source_meta_by_enabled`，按后台启用顺序过滤渠道元数据（未知/重复 key 丢弃），纯函数便于单测。
2. `api_vue_resource_search_resources`：`get_enabled_sources(media_type)` 优先；未启用任何渠道时直接返回提示，不再无谓搜索；渠道名随响应消息返回。
3. 候选条目补 `source_name`、`unlock_points`、`cost_label`（免费 / 已解锁 / N 积分）。
4. 前端 `MediaDrawer.vue`：结果卡片渲染渠道标签（主色）与积分标签（免费绿 / 付费琥珀），搜索提示改为「只查后台启用的渠道」。
5. `core/api/sync.py`：`sync/manual` 在无链接且候选为未解锁资源时，改为明示「HDHive 需 8 积分（解锁后才能取得分享链接）」，不再说「请填写资源链接」。

## 验证

- 单测 `tests/test_search_source_filter.py` 5 例通过：只留启用渠道、按启用顺序、去重与未知 key、空列表、大小写不敏感。
- `scripts/lint.py --all`：459 文件，0 error（427 存量 warning）。
- 前端 `vite build` 通过，dist 已更新。
- 未做线上回归：需在插件市场升级到 1.9.62 后复看抽屉搜索只剩 PanSou、卡片带渠道与「免费」标签。

## 遗留

- 付费渠道（HDHive / Dian115）目前只能提示积分数，不做自动解锁；是否允许「确认后花积分解锁并转存」待用户决定。

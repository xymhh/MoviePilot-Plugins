# 搜索口径拆分：资源页走上游、追更抽屉走启用渠道（1.9.64）

> 状态：已完成 2026-11-06，对应 v1.9.64

## 需求（用户原话）

> 修改一下，网盘资源页面还是按照上游的逻辑，只修改追更列表为我提的逻辑，并添加搜索源切换功能，当前是混在一起

## 问题

1.9.62 把「只查后台启用渠道」的过滤加在了 `resource/search_resources` 上，而**网盘资源页和追更列表抽屉共用这一个接口**，结果资源页的渠道 Tabs 也被削成只剩 `pansou`（用户实测：`available_sources: ['pansou']`），原本按渠道分 Tab 的上游交互被破坏。

## 改法

### 后端 `core/api/search.py`

- 新增请求参数 `enabled_only`（默认 `false`）。
  - `false`（网盘资源页）：`available_sources` 与可搜渠道 = **全部已注册渠道**，恢复上游行为；前端继续按渠道分 Tab 各自搜索。
  - `true`（追更抽屉）：先按 `search_source_order` 过滤，空配置时直接返回「后台未启用搜索渠道」。
- 两种口径都在响应 `data` 里补 `enabled_sources`（`key/name/icon/color` 元信息），供抽屉渲染切换标签。
- `source` 参数校验改为对照当前口径的渠道列表。

### 前端 `components/dashboard/MediaDrawer.vue`

- 请求带 `enabled_only: true`。
- 搜索面板新增「搜索源」一行标签：`全部 (N)` + 每个启用渠道 `(n)`，默认「全部」；点某个渠道只显示该站候选。
- 渠道数 ≤1 时不显示这一行（没得切）。
- 换剧 / 重新搜索时重置回「全部」。

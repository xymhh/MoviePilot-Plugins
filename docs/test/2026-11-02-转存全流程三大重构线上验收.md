## 二、改动点复核与证据

1. **`plugins.v2/cloudsubscribex/handlers/sync/matching.py`**：
   - 移除原有对发布标题做全等（`==`）的错误逻辑，改为 `resource_title_matches` 词边界包含比对；
   - 增加对夸克混淆父目录名（如 `2026犯罪《你-能-看-到-一-切》`）的去标点字串包含比对；
   - 增加对多视频中主视频（体积占比优势）的自动拾取。
2. **`plugins.v2/cloudsubscribex/drive/quark/share.py` & `resources.py`**：
   - 夸克驱动层不再把底层异常静默吞为 `[]`，统一抛出具体 `RuntimeError`；
   - `resources.py` 捕获后记录为 `KIND_INVALID`，防止流到 `KIND_EMPTY` 误报「无可用文件」。
3. **`plugins.v2/cloudsubscribex/handlers/sync/candidate_filter.py` & `television.py`**：
   - 增加 6 小时集号差负缓存 `remember_episode_miss` 与 `episode_miss_seen`，同批未更新剧集不再反复调 API 读目录。
4. **单测套件**：
   - 新增 `tests/test_transfer_refactor.py` 覆盖 3 大场景，全量 **1274 passed / 0 failed / 62 subtests passed**。

## 根因（对象链断裂）

```
P115UploadService (OwnerDelegator)
  └─ _owner = P115ClientManager      ← 不是插件实例
       └─ __getattr__ = resolve_component(self, _COMPONENT_TYPES, ...)
            └─ 只解析职责组件，**不转发**到插件
```

于是 `getattr(self._owner, "_cross_transfer_upload_proxy", "")` **恒为空串** →
`oss_request_kwargs("")` → `{}` → `session` 从未注入。

1.9.78/1.9.79 的注入代码本身是对的（`oss_multipart_*` + `p115oss.upload_file` 都传 `**proxy_kwargs`），
**但取不到代理地址**，所以整条链路静默直连。这也是为什么之前几轮「本地全绿」却真机无效 ——
测试注入的 owner 是假对象，恰好带 `_cross_transfer_upload_proxy` 属性。

## 修复

`drive/p115/upload.py::_oss_proxy_kwargs`：改为直接读 `self._owner._upload_proxies`

`{"http": ..., "https": ...}`），保留旧属性作为兼容回退；新增一次性
